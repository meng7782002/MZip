# 压缩解压工具 需求规格说明书

- 版本：v1.1（新增 Windows 系统集成需求：默认解压程序、资源管理器右键菜单）
- 日期：2026-11-02 13:11
- 项目：QuickZip（WPF / .NET 8）

## 1. 项目目标

提供一款 Windows 桌面端压缩/解压工具，支持 ZIP、7Z 的创建与解压，支持 RAR 的解压，界面简洁、操作直观，可作为日常文件归档工具使用；并深度集成 Windows 资源管理器，成为 ZIP/RAR/7Z 的默认解压程序。

## 2. 技术约束

| 项目 | 约定 |
| --- | --- |
| 界面框架 | WPF，.NET 8（不使用 MVVM 框架，直接使用实体类，不使用接口化开发） |
| 压缩引擎 | 内置 7-Zip 官方命令行（LGPL，可商用免费），支持 RAR/7Z/ZIP 等格式 |
| 日志 | log4net，记录所有异常与关键过程节点，日志文件输出到程序目录 logs 下 |
| 文档 | 统一存放于项目根目录 docs，文件名以“年月日时分”为前缀，修改生成新版本文件 |
| 密码 | 密码明文保存（仅在运行期内存与会话中使用），不做加密处理 |
| 系统集成 | 仅写入当前用户注册表 HKCU，不要求管理员权限，不修改 HKLM |

## 3. 功能需求

### 3.1 打开与浏览
- FR-01 通过“打开”按钮、文件菜单、拖拽窗口打开压缩包（支持 .zip/.7z/.rar/.tar/.gz/.bz2/.xz/.iso 等 7-Zip 支持的格式）。
- FR-02 打开加密压缩包时提示输入密码；密码错误给出明确提示，允许重新输入。
- FR-03 以列表方式展示压缩包内容：名称、大小、压缩后大小、压缩率、修改时间、CRC、属性、是否加密。
- FR-04 列表支持按名称排序、多选、双击解压选中项。
- FR-05 显示压缩包路径、格式、总文件数、原始总大小、压缩后总大小、压缩率。
- FR-06 记住最近打开的压缩包（最近 10 个），可从菜单快速打开。

### 3.2 解压
- FR-10 “解压全部”将全部内容解压到指定目录（默认：压缩包所在目录下同名文件夹）。
- FR-11 “解压选中”仅解压列表中选中的条目。
- FR-12 解压前可指定输出目录，目录默认记住上次选择。
- FR-13 解压过程显示进度百分比、当前处理文件，并提供取消按钮。
- FR-14 解压已存在文件时提供覆盖确认策略（覆盖 / 跳过 / 自动重命名）。
- FR-15 解压完成后可一键打开输出目录。

### 3.3 新建压缩包
- FR-20 “新建压缩包”可选择文件/文件夹，格式支持 7Z、ZIP，可设置压缩级别（1-9 / 仅存储）、密码。
- FR-21 压缩包内路径以所选条目的原始名称作为根，保留目录结构。
- FR-22 显示压缩进度与取消按钮，完成后自动打开该压缩包并刷新列表。
- FR-23 7Z 格式可选项：加密文件名（仅 7Z 支持）。

### 3.4 修改压缩包
- FR-30 “添加文件”向当前压缩包追加文件/文件夹（ZIP/7Z）。
- FR-31 “删除选中”从当前压缩包删除选中条目（ZIP/7Z；RAR 不支持修改，菜单置灰并提示）。
- FR-32 修改完成后自动刷新列表。

### 3.5 校验
- FR-40 “测试压缩包”执行完整性校验，显示成功/失败结果与错误信息。

### 3.6 其他
- FR-50 状态栏显示当前操作状态与进度条。
- FR-51 设置项：默认压缩格式、压缩级别、覆盖策略、默认输出目录、Windows 集成开关，保存在程序目录 config/settings.json。
- FR-52 所有异常写入日志，界面以中文友好提示。
- FR-53 支持中文文件名（UTF-8 输出），不出现乱码。

### 3.7 Windows 系统集成（新增）

- FR-60 **设为默认解压程序**：在设置界面提供“设为默认解压程序”，把本程序注册为 `.zip`、`.rar`、`.7z` 的打开程序（当前用户 HKCU，无需管理员权限），并注册应用能力信息，使程序出现在 Windows“默认应用”列表中。
- FR-61 **打开默认应用设置**：提供按钮直接跳转 Windows“默认应用”设置页，供用户在系统层面确认默认关联（Windows 10/11 的 UserChoice 受系统保护，程序不能静默强制修改）。
- FR-62 **取消关联**：提供“取消默认关联”操作，移除本程序写入的扩展名关联与 ProgID。
- FR-63 **右键压缩**：在资源管理器中选中一个或多个文件/文件夹，右键菜单出现“使用 QuickZip 压缩”；执行后在本目录生成压缩包（7Z 或 ZIP 按默认格式），文件名规则：
  - 单个文件夹 → `<文件夹名>.7z/zip`
  - 单个文件 → `<文件名（不含扩展名）>.7z/zip`
  - 多个条目 → `<所在目录名>.7z/zip`
  - 若同名压缩包已存在，自动追加 `(1)`、`(2)` 等序号，不覆盖既有文件。
- FR-64 **右键解压到本目录**：右键单击 `.zip/.rar/.7z` 文件，菜单出现“解压到本目录”，直接解压到压缩包所在目录；加密压缩包弹出密码框；按设置中的覆盖策略处理同名文件。
- FR-65 **右键解压到指定目录**：右键菜单出现“解压到指定目录…”，弹出目录选择后解压。
- FR-66 **注册/移除右键菜单**：设置界面提供开关键，控制上述右键菜单项的注册与移除；注册后通知资源管理器刷新图标与关联。
- FR-67 **多选压缩**：一次选中多个文件/文件夹执行右键压缩时，应合并生成一个压缩包，而不是每个条目各生成一个。
- FR-68 所有系统集成操作写入日志（注册、移除、失败原因）。

## 4. 非功能需求

- NFR-01 大文件解压/压缩不阻塞界面（后台线程 + 进度回报），可取消。
- NFR-02 单次操作资源占用受控，不将压缩包整体载入内存。
- NFR-03 程序可在 Windows 10/11 x64 上直接运行（自带 .NET 8 运行时依赖说明）。
- NFR-04 内置 7-Zip 版本信息在“关于”中展示，并附 LGPL 授权说明。
- NFR-05 系统集成仅限当前用户，不弹出 UAC，不修改系统级 HKLM 关联。

## 5. 验收标准

1. 可创建 ZIP、7Z 压缩包，压缩包可被 Windows 资源管理器 / 7-Zip 正常解压。
2. 可解压 ZIP、7Z、RAR（含 RAR5 与加密 RAR，密码正确时）。
3. 中文文件名在压缩/解压全流程无乱码。
4. 进度显示准确（百分比单调递增），取消后进程终止且不残留临时文件。
5. 删除、追加后重新打开压缩包内容正确。
6. 日志文件包含启动、打开、解压、压缩、异常等记录。
7. 执行“设为默认解压程序”后，`.zip/.rar/.7z` 可从“打开方式”选择 QuickZip；在 Windows 默认应用设置中可看到 QuickZip。
8. 注册右键菜单后：
   - 选中单个/多个文件或文件夹 → 右键出现“使用 QuickZip 压缩”，执行生成一个压缩包到本目录；
   - 右键 `.zip/.rar/.7z` → 出现“解压到本目录”“解压到指定目录…”，分别解压到本目录/所选目录；
   - 移除右键菜单后上述菜单项消失。
