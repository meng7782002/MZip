# 360压缩 功能对比分析报告

- 版本：v1.0
- 日期：2026-11-07 09:33
- 项目：MZip（WPF / .NET 8）
- 目的：对比 360压缩（4.0 最新版）与 MZip 当前功能，确定本轮"功能对齐 360压缩"的开发范围。

## 1. 360压缩功能总览

来源：360压缩官网（yasuo.360.cn）、官方帮助页、更新日志、360软件宝库及第三方评测。

### 1.1 格式支持
- 解压：RAR（含 RAR5）、ZIP、7Z、ISO、TAR、GZ、BZ2、ARJ、CAB、JAR、IMG、Z01 等 42 种以上格式
- 创建：ZIP、7Z、EXE 自解压包三种；安装 WinRAR 插件后可创建 RAR（个人免费、禁止商用）
- 引擎：7-Zip（LGPL）+ WinRAR 插件双核

### 1.2 压缩功能
- 压缩级别：存储 / 最快 / 标准 / 最好，含"速度最快""体积最小"快捷预设
- 分卷压缩（自定义分卷大小）
- 自解压 EXE 包（可设默认解压路径）
- 加密：AES-256，支持中文密码
- 7Z 固实压缩
- 压缩包注释
- 压缩完成后删除源文件
- 智能 CPU 优化（降低压缩时资源占用）
- 记忆上次压缩参数

### 1.3 解压功能
- 解压到当前文件夹 / 指定文件夹 / 以压缩包名命名的文件夹
- 多选压缩包"分别解压到独立文件夹"
- 批量解压、加密包批量解压并记住密码
- 解压后自动选中文件 / 自动关闭窗口
- 解压完成后删除源压缩包
- 磁盘空间不足提醒
- tar.gz / tar.bz2 一次解完（不解出中间 tar）
- 分卷包智能识别（防止文件夹名乱序）
- 乱码修复：压缩包语言切换编码 + UTF-8 自动检测

### 1.4 包内浏览与操作
- 包内图片免解压连续看图（独立图片查看器）
- 缩略图视图
- 包内 PDF 预览（可打印）
- 包内文件搜索
- 包内 MD5 计算与复制
- 包内直接拖拽解压（含拖到聊天窗口）
- 双击运行包内可执行文件时安全拦截
- 一键测试压缩包
- 损坏压缩包智能修复 / 免修复直接解压

### 1.5 右键菜单
- 添加到压缩文件…（弹配置对话框）
- 添加到"xx.zip"
- 添加到高压缩比"xx.7z"（固实）
- 解压文件…
- 解压到当前文件夹
- 解压到"xx\"
- 修复压缩包
- 智慧右键菜单（悬停预览包内容）、菜单可层叠折叠

### 1.6 界面与工具箱
- 简洁 / 经典双界面、RAR 风格主题
- 皮肤换肤、高清屏适配、多标签页
- 工具箱：MD5 校验工具、看图工具、图片批量无损压缩、密码管理（自动保存密码、加密包自动遍历密码）、超级压缩包（个性背景+超级注释）、AI 办公入口

### 1.7 特色服务
- 云安全引擎：压缩包木马扫描、包内文件安全评级（木马/脚本/风险）
- 主页防护
- 在线自动升级
- 配置绿色化（ini）、支持 Win7–Win11、多语言

## 2. MZip 当前功能（v1.9）

已实现：
- 打开/浏览：ZIP/7Z/RAR/TAR/GZ/BZ2/XZ/ISO 等 7-Zip 支持的全部格式；列表展示名称/大小/压缩率/CRC/加密标记；排序、多选、双击解压；最近文件 10 条
- 解压：全部/选中解压、进度+取消、覆盖策略（覆盖/跳过/自动重命名）、完成后打开目录
- 压缩：新建 ZIP/7Z（1-9 级/仅存储）、密码、7Z 加密文件名、进度+取消
- 修改：包内添加、删除（ZIP/7Z）
- 校验：测试压缩包
- 复制粘贴：Ctrl+A/C/V，跨包粘贴
- 系统集成：HKCU 注册默认解压程序（zip/rar/7z）、右键"压缩/解压到本目录/解压到指定目录"、多选合并压缩、图标关联与备份恢复
- 关于窗口、安装包（Inno Setup、免 UAC、静默安装）
- 日志：log4net 全流程记录

## 4. 本轮开发范围（对齐 360压缩核心压缩能力）

### 4.1 压缩增强
1. 新建压缩对话框重构：格式（ZIP/7Z/EXE 自解压）、压缩级别快捷预设（存储/最快/标准/最好）、分卷大小（可选）、固实压缩（7Z）、注释（ZIP/7Z）、压缩后删除源文件、记忆上次参数
2. 自解压 EXE：内置 7z.sfx 模块，生成双击即可解压的 exe
3. 分卷压缩：支持自定义分卷大小（MB），输出 .7z.001 / .zip.001 系列

### 4.2 解压增强
4. 批量解压：主界面"批量解压"支持多选压缩包，各自解压到独立同名文件夹；队列执行、统一进度
5. 解压完成后删除源压缩包（选项）
6. 磁盘空间不足预判与提醒
7. tar.gz / tar.bz2 一次解完（不残留中间 tar）
8. 乱码修复：打开压缩包时可切换文件名编码（GBK/Shift-JIS/Big5/UTF-8 等），实时刷新列表

### 4.3 密码管理
9. 密码库：本地明文保存已用密码（config/passwords.json），打开加密包时自动依次尝试，成功则记住；密码输入框可下拉选择历史密码；设置页可管理（查看/删除）密码库

### 4.4 包内浏览增强
10. 包内搜索框：按名称模糊过滤
11. 图片预览：双击包内图片（png/jpg/jpeg/bmp/gif/webp）弹出预览窗口，免解压到磁盘
12. MD5 校验工具：菜单"工具 → MD5 校验"，支持拖拽文件计算 MD5/SHA1/SHA256，支持粘贴比对；包内条目右键"计算 MD5"并复制

### 4.5 压缩包修复
13. 修复压缩包：菜单"工具 → 修复压缩包"，对 ZIP 尝试重建尾部目录并输出修复副本；右键菜单同步增加

### 4.6 右键菜单增强
14. 新增右键项：
    - 文件/文件夹：添加到"xx.zip"、添加到高压缩比"xx.7z"（固实）、添加到压缩文件…（打开主程序压缩对话框并带入所选路径）
    - 压缩包：解压文件…（弹目录选择）、修复压缩包
    - 层叠收纳：全部项收纳进"MZip"级联菜单，保持资源管理器菜单整洁

## 5. 明确不做的功能及原因

| 功能 | 原因 |
| --- | --- |
| RAR 创建 | WinRAR 插件仅个人免费、禁止商用，存在授权风险 |
| 云安全扫描/木马查杀/安全评级 | 依赖 360 云端安全引擎与病毒库，无法本地复刻 |
| AI 办公、图片压缩、超级压缩包 | 属于 360 生态周边工具，超出压缩软件核心范畴 |
| 在线自动升级 | 需搭建更新服务器与签名体系，本期无此基础设施 |
| 皮肤换肤/多标签/智慧右键预览 | 交互改造工作量大，本期优先对齐核心压缩能力 |
| 包内 PDF 预览 | 需引入 PDF 渲染组件，体积与复杂度高，本期不做 |

## 6. 验收要点（本轮新增）

1. 可创建 ZIP/7Z/EXE 自解压包，EXE 双击可解压
2. 可创建分卷压缩包，分卷可被 7-Zip 正常识别解压
3. 固实压缩 7Z 可被 7-Zip 打开且体积优于非固实
4. ZIP 注释在 7-Zip/Windows 中可见
5. 勾选"压缩后删除源文件"压缩成功后源文件被移除
6. 批量解压 N 个压缩包生成 N 个独立文件夹，无串目录
7. 勾选"解压后删除源压缩包"解压成功后压缩包被移除
8. 磁盘剩余空间不足时解压前弹出提醒且不开始解压
9. tar.gz 解压后直接得到最终文件，无中间 tar
10. 打开 GBK 编码压缩包乱码时，切换编码后文件名显示正常
11. 密码库：加密包密码输入一次后记住，再次打开自动解锁；错误密码自动尝试下一条
12. 包内搜索可实时过滤列表
13. 双击包内图片弹出预览窗口，可缩放、可切换上一张/下一张
14. MD5 工具计算结果与 certutil 一致；包内条目可一键计算并复制 MD5
15. 损坏 ZIP 经修复后尽可能恢复出可用文件（尽力而为，不保证 100%）
16. 右键菜单出现级联"MZip"菜单，包含全部压缩/解压/修复项
