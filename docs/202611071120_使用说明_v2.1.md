# MZip 使用说明

- 版本：v2.1
- 日期：2026-11-07 11:20
- 适用程序：MZip（WPF / .NET 8，内置 7-Zip 引擎）
- 变更说明：在 v2.0 基础上新增安装自动集成（安装时自动注册右键菜单与压缩文件关联、卸载时自动清理），并补充 `/register`、`/unregister` 静默命令说明。

## 1. 运行环境与启动

- 系统要求：Windows 10/11 x64；使用安装包安装时无需预装 .NET 8 Desktop Runtime（安装包已自带运行时）。
- 发布目录内需包含 `tools\7z.exe`、`tools\7z.dll`、`tools\7z.sfx`（构建/发布时自动复制，7z.sfx 为自解压 EXE 模块）。
- 双击 `MZip.exe` 启动；也可将压缩包拖到程序图标上，或使用命令行 `MZip.exe "压缩包路径"` 直接打开。
- 程序图标会显示在可执行文件、任务栏、窗口标题栏和"关于"窗口中。

### 1.1 安装与卸载

安装：

1. 双击 `MZip-1.0.0-Setup.exe`（由打包脚本生成，位于项目 `dist` 目录）。
2. 默认安装到 `%LOCALAPPDATA%\Programs\MZip`，全程无需管理员权限；如需更换位置可在安装界面修改。
3. 默认创建"开始菜单 → MZip"快捷方式；勾选"创建桌面快捷方式"可同时创建桌面图标。
4. **安装程序会在文件复制完成后自动注册右键菜单与压缩文件关联**（状态提示"正在注册右键菜单与文件关联…"），无需进入设置手动点击；注册只写入当前用户（HKCU），不影响其他账户。
5. 安装完成后可直接勾选"运行 MZip"。

静默部署（可选）：`MZip-1.0.0-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /DIR="D:\Apps\MZip"`，静默安装同样会自动注册。

卸载：

- 打开 Windows"设置 → 应用 → 已安装的应用"，找到 MZip 后点击"卸载"；或运行安装目录中的 `unins000.exe`。
- **卸载前会自动调用程序清理本程序写入的右键菜单与文件关联**（此步在程序文件删除前执行），压缩文件图标按安装前的备份恢复，无需手动"取消关联"。
- 卸载会移除程序文件、快捷方式与卸载登记项；`config\settings.json`（设置）、`config\passwords.json`（密码库）与 `logs`（日志）会保留，如需彻底清理可手动删除安装目录。
- 若注册/反注册过程失败（例如安全软件拦截），不会阻断安装或卸载：安装失败后可在"设置 → Windows 系统集成"中手动重试，卸载失败后可在卸载前手动点击"取消关联""移除右键菜单"。

## 2. 支持格式

| 能力 | 格式 |
| --- | --- |
| 解压 / 浏览 / 测试 | ZIP、7Z、RAR、TAR、GZ、TGZ、BZ2、XZ、ISO、CAB、JAR、APK、分卷 001 等 |
| 新建 / 添加 / 删除条目 | ZIP、7Z |
| 自解压 EXE | 基于 7Z 数据 + 7z.sfx 模块生成，双击即可解压 |
| 加密 | ZIP（AES-256）、7Z（可加密文件名） |
| 修复 | 仅 ZIP |

RAR 为专有压缩格式，免费引擎只能解压，不能创建或修改。

## 3. 打开压缩包

- 点击工具栏"打开"或菜单"文件 → 打开压缩包…"，快捷键 Ctrl+O。
- 从"文件 → 最近打开"中快速选择最近使用的压缩包（最多 10 条）。
- 空状态下直接把压缩包拖入窗口即可打开。
- 加密文件名的 7Z/RAR 会弹出密码框；密码错误会提示并允许重新输入。
- **密码库自动尝试**：打开加密压缩包时，程序会先自动尝试密码库中保存的密码（按最近使用顺序），命中则直接打开并在状态栏提示"第 n 条命中"；全部失败才弹出密码框。成功使用的密码自动加入密码库（见第 8 节）。

### 3.1 文件名乱码（编码切换）

- 打开老压缩包（如 GBK/Big5/Shift-JIS 年代创建的 ZIP）出现文件名乱码时，在工具栏"编码"下拉框中切换对应代码页，列表会立即按新编码重新读取。
- 默认"自动"按 UTF-8/本地编码自动识别；经常打开某类历史压缩包时，可在"设置 → 默认文件名编码"中固定代码页。
- 切换编码会写入日志。

### 3.2 包内搜索

- 打开压缩包后，在工具栏搜索框输入关键字即按条目路径实时过滤（300 毫秒防抖，无需回车）。
- 状态栏显示"已过滤 x / 共 y 项"；清空搜索框或打开新压缩包时恢复完整列表。

### 3.3 图片预览

- 双击单个图片条目（jpg / jpeg / png / bmp / gif / webp / ico）直接弹出预览窗口，不落盘。
- 预览窗口支持：滚轮缩放（5% ~ 800%）、"适应窗口"、"实际大小（100%）"、左右方向键切换上/下一张、Esc 关闭；GIF 显示首帧静态图。
- 解压后超过 50 MB 的图片不预览，请先解压再查看。

## 4. 浏览与解压

- 列表显示条目完整路径、大小、压缩后大小、压缩率、修改时间、CRC、属性，加密条目带"加密"徽章。
- "解压全部"：选择输出目录后解压全部内容。
- "解压选中"：在列表中选中一个或多个条目（支持 Ctrl/Shift 多选），点击"解压选中"或双击条目（图片条目双击为预览）。
- 覆盖策略在"设置"中配置：每次询问 / 直接覆盖 / 跳过已有 / 自动重命名。
- 解压前自动检查目标磁盘剩余空间，不足时提示并中止。
- 解压完成后可选择是否打开输出目录；在"设置"中勾选"解压完成后删除源压缩包"可在解压成功后自动删除源包（分卷序列整体删除，删除失败仅提示不影响解压结果）。

### 4.1 批量解压

- 菜单"工具 → 批量解压…"打开批量解压窗口：添加多个压缩包（可拖入），统一选择输出根目录，逐个解压到以压缩包命名的子文件夹。
- 每个包独立执行，单个失败不影响其余；结束后显示成功/失败汇总。
- 右键多选压缩包选择批量解压命令时自动带入列表（见第 9 节）。

### 4.2 复制条目并粘贴到指定位置

1. 打开压缩包后，按 Ctrl+A 或"操作 → 全选条目"选中全部文件（也可用 Ctrl/Shift 手动多选部分条目）。
2. 按 Ctrl+C 或"操作 → 复制选中条目"，状态栏提示已复制的条目数量；列表右键菜单同样提供这两个命令。
3. 按 Ctrl+V 或"操作 → 粘贴到指定文件夹…"，选择目标文件夹，条目会直接解压到该文件夹（不再创建同名子目录）。
4. 覆盖策略按"设置"中的配置执行；设置为"每次询问"时会弹出覆盖策略对话框。
5. 粘贴使用复制时的来源压缩包：即使之后打开或关闭了其他压缩包仍可粘贴；若来源文件已被删除或移动，会提示且不解压。

## 5. 新建压缩包

1. 点击"新建"，在对话框中添加文件或文件夹（可多选，也可由右键"添加到压缩文件…"带入）。
2. 选择格式：7Z / ZIP / EXE（自解压包）；选择压缩级别（0 存储 ~ 9 极限）。
3. 可选设置密码；7Z 支持"加密文件名"，ZIP 使用 AES-256 加密。
4. 可选高级项：
   - **固实压缩**（仅 7Z）：多文件作为一个整体压缩，大量小文件时压缩比更高，但解压单个文件会变慢；
   - **分卷大小**（MB，7Z/ZIP 支持，EXE 不支持）：按指定大小切分为 `.001`、`.002`… 序列，首卷/主包为 `.001`；
   - **压缩包注释**（仅 ZIP）：写入 ZIP 注释，打开时可见；
   - **压缩后删除源文件**：压缩完成并通过完整性校验后才删除源文件/文件夹，校验失败自动保留。
5. 确认保存路径（默认根据来源自动建议），点击"创建"。
6. 创建完成后自动打开生成的压缩包；对话框会记忆上次使用的格式/级别/分卷/固实等参数（密码不记忆）。

自解压 EXE 说明：生成的是标准 7Z 自解压包，双击后按提示解压到指定目录；EXE 不支持分卷。若提示"自解压模块 7z.sfx 缺失"，请确认 `tools\7z.sfx` 存在。

不能将压缩包保存到被压缩的文件夹内部，程序会阻止并提示。

## 6. 修改压缩包（仅 ZIP / 7Z）

- "添加"：向当前压缩包追加文件或文件夹；已打开压缩包时也可以直接把文件拖入窗口。
- "删除"：删除选中条目，操作不可撤销，执行前会二次确认。
- "刷新"（F5）：重新读取条目列表。

## 7. 校验、MD5 与修复

### 7.1 完整性校验与取消

- "测试"执行完整性校验，成功或失败均给出结果提示。
- 操作过程中状态栏显示进度条与百分比，点击"取消"或按 Esc 可终止当前操作。

### 7.2 MD5 校验工具

- 菜单"工具 → MD5 校验…"打开校验窗口：拖入文件或点击"浏览"选择文件，自动计算 **MD5 / SHA1 / SHA256 / CRC32** 四种值，每行带"复制"按钮。
- 将官方提供的校验值粘贴到"期望校验值"框，自动比对：一致显示绿色 ✓，不一致显示红色 ✗（按 MD5/SHA1/SHA256 长度自动识别算法）。
- 大文件计算显示进度条，可随时取消。
- 包内条目：在条目列表右键单个文件条目选择"计算 MD5"，流式解出后计算并弹窗展示（不落地临时文件）。

### 7.3 修复压缩包（仅 ZIP）

- 菜单"工具 → 修复压缩包…"选择受损 ZIP，程序扫描本地文件头重建中央目录，在同目录输出 `<原名>_repaired.zip`（重名自动追加时间戳，不覆盖原文件）。
- 修复为尽力而为：中央目录损坏、文件尾部截断等场景通常可恢复未受损部分；恢复条目数与跳过条目数在结果弹窗中给出。
- RAR/7Z 等其他格式暂不支持修复。
- 修复完成后请立即验证修复后的压缩包内容。

## 8. 设置与密码库

菜单"工具 → 设置"可调整：

- 默认压缩格式（7Z / ZIP）
- 默认压缩级别
- 覆盖策略
- 默认输出目录
- 默认文件名编码（0 = 自动）
- 解压完成后删除源压缩包
- 右键菜单级联收纳开关（见第 9 节）
- Windows 系统集成（见第 9 节）

设置以明文 JSON 保存在程序目录 `config\settings.json`。

### 8.1 密码库

- 成功打开加密压缩包的密码、创建加密压缩包时使用的密码，会按"最近使用优先"自动保存到 `config\passwords.json`（最多 50 条，**明文存储**）。
- 设置窗口"密码库管理"卡片中可查看、删除单条或清空全部。
- 密码库为明文文件，请勿共享程序目录；公用电脑建议定期清空。

### 8.2 关于 MZip

点击菜单"工具 → 关于"或工具栏"关于"按钮，可查看程序版本、内置 7-Zip 引擎版本，以及作者邮箱 593192219@qq.com。右键 `MZip.exe` → 属性 → 详细信息可查看版本等元数据。

## 9. Windows 系统集成

所有注册项只写入当前用户注册表（HKCU），无需管理员权限，也不影响其他用户账户。

安装包安装完成后会**自动完成**以下两项注册（等价于在设置中手动点击"设为默认解压程序"和"注册右键菜单"）；绿色版或卸载后需要恢复时，按本节步骤手动操作即可。

### 9.1 关联为默认解压程序

1. 打开"设置"，在"Windows 系统集成"卡片中点击"设为默认解压程序"。
2. 程序会把 `.zip`、`.rar`、`.7z` 注册为 MZip 可打开的类型，并在注册表中登记应用能力（"打开方式"列表中可见）。
3. 同时为这三类扩展名写入 MZip 图标，资源管理器中的压缩文件会立即显示该图标（无需重启资源管理器）。
4. Windows 10/11 的"默认应用"由系统哈希保护，程序不能强行改写。需要完全成为默认程序时，点击"打开默认应用设置"，在"按文件类型指定默认应用"中把 `.zip` / `.rar` / `.7z` 选择为 MZip。
5. 点击"取消关联"可撤销 MZip 写入的所有关联项，并把压缩文件图标恢复为注册前的状态。

状态文字会实时显示"已注册 / 未注册"。

### 9.2 资源管理器右键菜单

在"设置"中点击"注册右键菜单"后：

| 操作对象 | 右键菜单项 | 行为 |
| --- | --- | --- |
| 文件/文件夹（可多选） | 使用 MZip 压缩 | 按上次使用的格式与级别在本目录生成压缩包 |
| 文件/文件夹（可多选） | 压缩为同名 ZIP 文件 | 按 ZIP 默认参数直接压缩，不弹对话框 |
| 文件/文件夹（可多选） | 压缩为高压缩比 7Z 文件 | 7Z + 极限级别 + 固实，直接压缩 |
| 文件/文件夹（可多选） | 添加到压缩文件… | 打开新建压缩对话框并自动带入所选路径 |
| .zip / .rar / .7z | 解压到本目录 | 在压缩包同级创建同名文件夹并解压 |
| .zip / .rar / .7z | 解压到指定目录… | 弹出目录选择框后解压 |
| .zip | 使用 MZip 修复 | 执行 ZIP 修复并输出 `_repaired.zip`（仅 ZIP 注册此项，其余格式不出现） |

说明：

- 多选时资源管理器会为每个条目启动一次进程，程序按命令类型隔离汇总路径（600 毫秒静默窗口），只保留一个主窗口，其余实例自动退出，多选压缩只生成一个压缩包。
- 同名压缩包已存在时自动追加序号，如 `备份 (1).zip`，不会覆盖已有文件。
- "解压到本目录"的目标文件夹若已存在则直接复用；文件夹内遇到同名文件时按"直接覆盖"处理（不弹询问），其他覆盖策略可在设置中改为跳过或自动重命名。
- 若压缩包同级已存在同名文件（而非文件夹），程序会提示并停止，避免误覆盖。
- 点击"移除右键菜单"可清理全部菜单项（含级联模式残留），随后资源管理器会自动刷新。

### 9.3 级联收纳开关与 Win11 注意事项

- 设置中勾选"级联收纳到'MZip'菜单"后，以上所有菜单项收纳到名为 **MZip** 的单个级联菜单中，顶层只占一行（带图标），展开后显示子项；取消勾选则退回平铺模式（默认）。
- **重要**：级联菜单基于纯注册表实现（`SubCommands` + `shell` 子键），**在 Windows 11 上仅经典右键菜单生效**（Shift+右键，或"显示更多选项"展开后可见）；Win11 新样式菜单只显示顶层一项，可能无法展开子项。Windows 10 不受影响。
- 因此默认平铺，保证所有命令在 Win11 新菜单中直接可见；切换开关后若菜单已注册会立即按新模式重写。
- 切换建议：Win11 用户保持默认平铺；Win10 用户或习惯经典菜单的用户可开启级联以保持右键菜单简洁。

### 9.4 注册表位置

| 用途 | 路径 |
| --- | --- |
| 文件类型 ProgID | `HKCU\Software\Classes\MZip.Archive` |
| 扩展名关联 | `HKCU\Software\Classes\.zip` / `.rar` / `.7z` |
| 文件图标 | `HKCU\Software\Classes\.zip\.rar\.7z` 下的 `DefaultIcon` |
| 图标原值备份 | `HKCU\Software\MZip\IconBackup` |
| 压缩菜单（平铺） | `HKCU\Software\Classes\*\shell\MZip.Compress` / `MZip.ZipQuick` / `MZip.7zSolid` / `MZip.AddTo`（`Directory\shell` 下同名一组） |
| 解压/修复菜单（平铺） | `HKCU\Software\Classes\SystemFileAssociations\.{zip,rar,7z}\shell\MZip.ExtractHere` / `MZip.ExtractTo`，修复仅 `.zip` 下的 `MZip.Repair` |
| 级联菜单 | `HKCU\Software\Classes\*\shell\MZip`、`Directory\shell\MZip`、`SystemFileAssociations\.{zip,rar,7z}\shell\MZip`（各含 `shell\01…` 子键） |
| 应用能力登记 | `HKCU\Software\MZip\Capabilities`、`HKCU\Software\RegisteredApplications` |

## 10. 命令行参数

`/` 与 `--` 前缀均可（如 `/zip` 与 `--zip` 等效）。

| 参数 | 说明 |
| --- | --- |
| `MZip.exe "压缩包路径"` | 启动并打开指定压缩包 |
| `MZip.exe --compress "路径1" ["路径2" …]` | 一键压缩，按上次格式自动命名生成 |
| `MZip.exe /zip "路径1" […]` | 按 ZIP 默认参数直接压缩到本目录，不弹对话框 |
| `MZip.exe /7zsolid "路径1" […]` | 7Z + 极限级别 + 固实直接压缩 |
| `MZip.exe /add "路径1" […]` | 打开主窗口并弹出新建压缩对话框，自动带入路径 |
| `MZip.exe --extract-here "压缩包路径"` | 解压到压缩包所在目录 |
| `MZip.exe --extract-to "压缩包路径"` | 选择目录后解压 |
| `MZip.exe /repair "压缩包路径"` | 修复 ZIP 并弹结果（仅 ZIP） |
| `MZip.exe /batch "包1" […]` | 打开批量解压窗口并带入列表 |
| `MZip.exe /register` | 静默注册右键菜单与压缩文件关联后立即退出（安装包自动调用，不显示窗口） |
| `MZip.exe /unregister` | 静默移除本程序写入的右键菜单与文件关联后立即退出（卸载程序自动调用） |

多路径参数（--compress、/zip、/7zsolid、/add、/batch）支持多选场景自动汇总为一个操作。

`/register`、`/unregister` 为幂等操作：重复执行不会产生重复菜单项；执行结果写入日志，失败时退出码仍为 0，不阻断安装/卸载流程。

## 11. 日志

- 日志目录：程序目录下 `logs`，文件名为 `MZip<yyyy-MM-dd>.log`，按天滚动，保留约 30 份。
- 记录启动、命令参数、打开、解压/压缩/删除/校验、批量解压逐包结果、删除源文件逐项结果、编码切换、密码自动尝试（只记"第 n 条命中"，不记密码内容）、修复扫描/重建结果、MD5 计算、右键菜单注册与文件关联、图标注册与恢复、安装/卸载时的静默注册与反注册结果等关键节点，以及全部异常堆栈。
- 反馈问题时请附带对应日期的日志文件。

## 12. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示"压缩引擎缺失" | 确认 `tools` 目录下存在 `7z.exe` 与 `7z.dll`，杀毒软件可能误删 |
| 提示"自解压模块 7z.sfx 缺失" | 确认 `tools\7z.sfx` 存在；安装包已内置，绿色版请手动补齐 |
| 打开加密压缩包一直提示密码 | 确认密码正确；可先检查密码库中是否有匹配记录 |
| 中文文件名乱码 | 在工具栏"编码"下拉框切换到对应代码页（如 GBK）；老 ZIP 常见 |
| 解压提示"文件正在被其他程序使用" | 关闭占用该文件的程序后重试 |
| 解压提示磁盘空间不足 | 清理目标磁盘或更换输出目录 |
| 安装后右键菜单没有出现 | 先确认安装时未报错（安全软件可能拦截注册）；在设置中确认状态为"已注册"，或先移除再重新注册，必要时重启资源管理器 |
| 右键菜单未出现 | 在设置中确认状态为"已注册"，或先移除再重新注册；必要时重启资源管理器 |
| Win11 级联菜单点不开子项 | 级联仅在经典菜单生效：用 Shift+右键或"显示更多选项"，或在设置中关闭级联退回平铺 |
| 双击压缩包仍由旧程序打开 | Windows 默认应用受系统保护，请点击"打开默认应用设置"手动指定 |
| 压缩文件图标未变化 | Windows 图标缓存可能未刷新，取消关联后重新注册；或重启资源管理器 |
| 卸载后右键菜单仍在 | 卸载时若清理失败（安全软件拦截或程序文件被提前删除），可重新安装后手动"移除右键菜单"，或按第 9.4 节路径手动清理注册表 |
| 修复后的 ZIP 仍打不开 | 修复为尽力而为，损坏严重时仅能恢复部分条目；请查看修复结果中的恢复/跳过计数 |
| 安装包不包含 7z.sfx | v2.0 起发布流程自动复制 tools\7z.sfx；若使用旧脚本产物请重新打包 |
