# MZip 代码签名配置说明

- 版本：v1.0
- 日期：2026-11-07 11:05
- 适用：MZip 主程序（MZip.exe）与安装包（MZip-x.y.z-Setup.exe）
- 证书类型：自签名代码签名证书（本机/内部信任，非商业 CA 签发）

`certs` 目录已加入 `.gitignore`，私钥不进入版本库；换机或重建时运行生成脚本即可。

## 2. 首次配置 / 重新生成证书

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-codesign-cert.ps1
```

脚本执行内容：

1. 在 `Cert:\CurrentUser\My` 创建代码签名证书（Code Signing EKU，5 年有效）；
2. 导出 `certs\MZip-CodeSigning.pfx`（密码 123456）与 `.cer`；
3. 将 `.cer` 导入 `Cert:\CurrentUser\Root` 与 `Cert:\CurrentUser\TrustedPublisher`，使本机签名验证为"有效"。

强制重新生成（旧证书作废）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-codesign-cert.ps1 -Force
```

脚本参数：`-Subject`（证书主题）、`-Password`（PFX 密码）、`-Years`（有效期年数）、`-Force`。

## 3. 签名命令

```powershell
# 仅签名指定文件（可多个）
powershell -ExecutionPolicy Bypass -File scripts\sign-artifacts.ps1 -Path dist\MZip-1.0.0-Setup.exe

# 同时签名主程序与安装包
powershell -ExecutionPolicy Bypass -File scripts\sign-artifacts.ps1 -Path build\publish\MZip.exe, dist\MZip-1.0.0-Setup.exe
```

脚本行为：

1. 优先使用当前用户证书库中带私钥的证书；缺失时自动从 `certs\MZip-CodeSigning.pfx` 导入；
2. 先尝试带 RFC3161 时间戳签名（默认 `http://timestamp.digicert.com`），网络不可用时退化为无时间戳签名；
3. 签名后校验 `Status` 必须为 `Valid`，否则脚本报错退出。

## 4. 构建流程集成

`scripts\build-installer.ps1` 已自动集成签名，完整流程：

1. `dotnet publish` 自包含发布到 `build\publish`；
2. 对 `build\publish\MZip.exe` 签名；
3. Inno Setup 编译安装包（安装包内已包含签名后的主程序）；
4. 对 `dist\MZip-<版本>-Setup.exe` 签名；
5. 输出安装包并记录日志（F:\AITEMP\MZip-installer-build.log）。

证书不存在时构建脚本会记录"跳过代码签名"并继续，不影响出包；需要签名时先执行第 2 节脚本。

> 安装包内附带的 `unins000.exe`（卸载程序）由 Inno Setup 生成，未单独签名；如需签名卸载程序，需在 `installer\MZip.iss` 中配置 `SignTool` + `SignedUninstaller=yes`，当前自签名方案未启用。

## 5. 验证签名

资源管理器：右键文件 → 属性 → 数字签名 → 应显示`MZip Development`且状态"有效"。

PowerShell：

```powershell
Get-AuthenticodeSignature dist\MZip-1.0.0-Setup.exe | Format-List Status, SignerCertificate, TimeStamperCertificate
```

已实测结果（2026-11-07）：主程序与安装包 `Status=Valid`，签名者 `CN=MZip Development, O=MZip, C=CN`，含时间戳；静默安装后的 `MZip.exe` 同样为 `Valid`。

## 6. 限制与注意事项

- **自签名仅本机（或手动导入根证书的机器）信任**。分发到其他电脑时，SmartScreen 仍可能提示"未知发布者"，安装界面发布者显示取决于目标机是否导入 `certs\MZip-CodeSigning.cer` 到"受信任的根证书颁发机构"。
- 若需对外正式分发，建议购买 OV/EV 代码签名证书：把新证书导出为 `certs\MZip-CodeSigning.pfx`（同文件名、同密码或修改 `sign-artifacts.ps1` 默认密码）即可，无需改动其他脚本。
- 证书有效期 5 年，到期前重新运行生成脚本并重新出包；已签名的旧文件不因新证书生成而失效。
- 私钥文件 `certs\MZip-CodeSigning.pfx` 切勿外传；卸载证书可在 `certmgr.msc` 当前用户"个人"存储中删除，并同步删除根/发布者存储中的同名证书。
- 签名会修改文件内容，必须在签名之后再打包/再计算校验值；本项目构建顺序已保证"先签主程序、再打包、再签安装包"。
