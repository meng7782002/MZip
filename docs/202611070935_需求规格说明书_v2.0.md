# 压缩解压工具 需求规格说明书

- 版本：v2.0
- 日期：2026-11-07 09:35
- 项目：MZip（WPF / .NET 8）
- 变更说明：本版本对齐 360压缩核心功能，新增 16 项功能需求（FR-90 ~ FR-118），详见《202611070933_360压缩功能对比分析_v1.0》。RAR 创建、云安全扫描、AI 办公、皮肤换肤、多标签页、智慧右键预览、包内 PDF 预览、在线自动升级等功能经评审明确不实现。

## 1. 项目目标

提供一款 Windows 桌面端压缩/解压工具，支持 ZIP、7Z 的创建与解压，支持 RAR 的解压，界面简洁、操作直观，可作为日常文件归档工具使用；并深度集成 Windows 资源管理器，成为 ZIP/RAR/7Z 的默认解压程序。v2.0 起核心压缩/解压能力对齐 360 压缩。

## 2. 技术约束

| 项目 | 约定 |
| --- | --- |
| 界面框架 | WPF，.NET 8（不使用 MVVM 框架，直接使用实体类，不使用接口化开发） |
| 压缩引擎 | 内置 7-Zip 官方命令行（LGPL，可商用免费），支持 RAR/7Z/ZIP 等格式；自解压包使用 7-Zip 官方 7z.sfx 模块 |
| 日志 | log4net，记录所有异常与关键过程节点，日志文件输出到程序目录 logs 下 |
| 文档 | 统一存放于项目根目录 docs，文件名以"年月日时分"为前缀，修改生成新版本文件 |
| 密码 | 密码明文保存（本地密码库与用户设置均明文），不做加密处理 |
| 系统集成 | 仅写入当前用户注册表 HKCU，不要求管理员权限，不修改 HKLM |
| 图标 | 使用自有版权图标文件（ICO 多尺寸），嵌入可执行文件，不依赖第三方素材授权 |

## 3. 功能需求

### 3.1 打开与浏览
- FR-01 通过"打开"按钮、文件菜单、拖拽窗口打开压缩包（支持 .zip/.7z/.rar/.tar/.gz/.bz2/.xz/.iso 等 7-Zip 支持的格式）。
- FR-02 打开加密压缩包时提示输入密码；密码错误给出明确提示，允许重新输入。
- FR-03 以列表方式展示压缩包内容：名称、大小、压缩后大小、压缩率、修改时间、CRC、属性、是否加密。
- FR-04 列表支持按名称排序、多选、双击解压选中项。
- FR-05 显示压缩包路径、格式、总文件数、原始总大小、压缩后总大小、压缩率。
- FR-06 记住最近打开的压缩包（最近 10 个），可从菜单快速打开。

### 3.2 解压
- FR-10 "解压全部"将全部内容解压到指定目录（默认：压缩包所在目录下同名文件夹）。
- FR-11 "解压选中"仅解压列表中选中的条目。
- FR-12 解压前可指定输出目录，目录默认记住上次选择。
- FR-13 解压过程显示进度百分比、当前处理文件，并提供取消按钮。
- FR-14 解压已存在文件时提供覆盖确认策略（覆盖 / 跳过 / 自动重命名）。
- FR-15 解压完成后可一键打开输出目录。

### 3.3 新建压缩包
- FR-20 "新建压缩包"可选择文件/文件夹，格式支持 7Z、ZIP，可设置压缩级别（1-9 / 仅存储）、密码。
- FR-21 压缩包内路径以所选条目的原始名称作为根，保留目录结构。
- FR-22 显示压缩进度与取消按钮，完成后自动打开该压缩包并刷新列表。
- FR-23 7Z 格式可选项：加密文件名（仅 7Z 支持）。

### 3.4 修改压缩包
- FR-30 "添加文件"向当前压缩包追加文件/文件夹（ZIP/7Z）。
- FR-31 "删除选中"从当前压缩包删除选中条目（ZIP/7Z；RAR 不支持修改，菜单置灰并提示）。
- FR-32 修改完成后自动刷新列表。

### 3.5 校验
- FR-40 "测试压缩包"执行完整性校验，显示成功/失败结果与错误信息。

### 3.6 其他
- FR-50 状态栏显示当前操作状态与进度条。
- FR-51 设置项：默认压缩格式、压缩级别、覆盖策略、默认输出目录、Windows 集成开关，保存在程序目录 config/settings.json。
- FR-52 所有异常写入日志，界面以中文友好提示。
- FR-53 支持中文文件名（UTF-8 输出），不出现乱码。

### 3.7 Windows 系统集成

- FR-60 **设为默认解压程序**：在设置界面提供"设为默认解压程序"，把本程序注册为 `.zip`、`.rar`、`.7z` 的打开程序（当前用户 HKCU，无需管理员权限），并注册应用能力信息，使程序出现在 Windows"默认应用"列表中。
- FR-61 **打开默认应用设置**：提供按钮直接跳转 Windows"默认应用"设置页，供用户在系统层面确认默认关联（Windows 10/11 的 UserChoice 受系统保护，程序不能静默强制修改）。
- FR-62 **取消关联**：提供"取消默认关联"操作，移除本程序写入的扩展名关联与 ProgID。
- FR-63 **右键压缩**：在资源管理器中选中一个或多个文件/文件夹，右键菜单出现"使用 MZip 压缩"；执行后在本目录生成压缩包（7Z 或 ZIP 按默认格式），文件名规则：
  - 单个文件夹 → `<文件夹名>.7z/zip`
  - 单个文件 → `<文件名（不含扩展名）>.7z/zip`
  - 多个条目 → `<所在目录名>.7z/zip`
  - 若同名压缩包已存在，自动追加 `(1)`、`(2)` 等序号，不覆盖既有文件。
- FR-64 **右键解压到本目录**：右键单击 `.zip/.rar/.7z` 文件，菜单出现"解压到本目录"，在压缩包所在目录下创建与压缩包同名的文件夹（不含扩展名），并解压到该文件夹内；同名文件夹已存在时直接复用该文件夹；加密压缩包弹出密码框；按设置中的覆盖策略处理同名文件；若同名路径是文件而非文件夹，给出提示并记录日志。
- FR-65 **右键解压到指定目录**：右键菜单出现"解压到指定目录…"，弹出目录选择后解压。
- FR-66 **注册/移除右键菜单**：设置界面提供开关键，控制上述右键菜单项的注册与移除；注册后通知资源管理器刷新图标与关联。
- FR-67 **多选压缩**：一次选中多个文件/文件夹执行右键压缩时，应合并生成一个压缩包，而不是每个条目各生成一个。
- FR-68 所有系统集成操作写入日志（注册、移除、失败原因）。

### 3.8 应用图标与压缩文件图标

- FR-69 **应用图标**：程序拥有专属图标（多尺寸 ICO），显示在可执行文件、桌面/开始菜单快捷方式、任务栏、窗口标题栏与"关于"窗口。
- FR-70 **压缩文件图标**：执行"设为默认解压程序"后，`.zip`、`.rar`、`.7z` 文件在资源管理器中统一显示为该图标；取消关联后恢复系统原有图标，不影响其他程序。
- FR-71 **图标即时生效**：注册/取消关联后立即通知资源管理器刷新图标缓存，无需手动重启资源管理器。
- FR-72 图标写入前备份扩展名原有的 `DefaultIcon` 值，取消关联时按备份恢复（原值为空则删除该值）。

### 3.9 复制与粘贴

- FR-73 **全选条目**：支持一次选中当前压缩包内的全部条目（"操作 → 全选条目"、列表右键菜单或 Ctrl+A）。
- FR-74 **复制选中条目**：将选中的条目复制到程序内部剪贴板（"操作 → 复制选中条目"、右键菜单或 Ctrl+C），同时记录来源压缩包路径与当前密码，状态栏提示已复制的条目数量。
- FR-75 **粘贴到指定位置**：通过"操作 → 粘贴到指定文件夹…"、右键菜单或 Ctrl+V，选择目标文件夹后把剪贴板中的条目解压到该文件夹（直接放入所选文件夹，不再创建同名子目录）。
- FR-76 粘贴时沿用设置中的覆盖策略；策略为"每次询问"时弹出覆盖策略对话框。
- FR-77 若剪贴板为空、来源压缩包已被删除或移动，给出中文提示并记录日志，不执行解压。
- FR-78 复制、粘贴的关键节点与失败原因写入日志。

### 3.10 关于信息

- FR-79 **关于窗口**：菜单"工具 → 关于"与工具栏"关于"打开关于窗口，展示程序名称、版本号、作者邮箱 593192219@qq.com，不再展示公司名称与版权信息。
- FR-80 关于窗口与安装包展示作者邮箱 593192219@qq.com；可执行文件属性不再填写公司信息。

### 3.11 Windows 安装包

- FR-81 **安装包形式**：提供 Windows x64 安装程序（`MZip-<版本>-Setup.exe`），双击即可完成安装，无需另行安装 .NET 8 运行时（安装包内含自包含发布产物）。
- FR-82 **安装位置**：默认安装到当前用户目录 `%LOCALAPPDATA%\Programs\MZip`，安装与卸载均不需要管理员权限，不弹出 UAC；允许用户在安装时修改目标目录。
- FR-83 **快捷方式**：安装后创建"开始菜单 → MZip"快捷方式，桌面快捷方式作为可选组件。
- FR-84 **安装内容**：安装目录包含 `MZip.exe`、依赖文件、`tools\7z.exe`、`tools\7z.dll`、`tools\License.txt`；程序首次运行后在安装目录生成 `config` 与 `logs`。
- FR-85 **卸载**：控制面板"应用"列表中可见 MZip，可正常卸载；卸载移除程序文件、快捷方式与注册表卸载项，保留 `config\settings.json` 与 `logs` 目录中的用户数据。
- FR-86 **静默安装**：支持 Inno Setup 标准静默参数（`/VERYSILENT /SUPPRESSMSGBOXES /DIR="路径"`），便于自动化部署与验证。
- FR-87 **版本一致**：安装包显示的应用名、版本号、发布者（MZip 作者）、图标与可执行文件元数据一致。

### 3.12 压缩增强（v2.0 新增，对齐 360 压缩）

- FR-90 **新建压缩对话框增强**：对话框支持以下选项——
  - 压缩格式：ZIP / 7Z / EXE 自解压包；
  - 压缩级别快捷预设：仅存储 / 最快 / 标准 / 最好（映射 7-Zip 的 -mx0/1/5/9）；
  - 分卷压缩：可填写分卷大小（MB），留空则不分卷；输出 `.7z.001`/`.zip.001` 分卷序列；
  - 固实压缩：7Z 格式可选"固实压缩"（-ms=on）；
  - 注释：ZIP/7Z 可填写压缩包注释（ZIP 写入归档注释；7Z 不支持注释时隐藏该项）；
  - 压缩后删除源文件：勾选后压缩成功并校验通过后删除原始文件/文件夹；
  - 密码与加密文件名（沿用 FR-20/FR-23）。
- FR-91 **记忆上次压缩参数**：对话框关闭时把格式、级别、分卷、固实、删除源文件等选项保存到 settings.json，下次打开自动回填（密码不回填）。
- FR-92 **自解压 EXE**：选择 EXE 格式时，使用内置 7z.sfx 模块生成自解压程序；生成的 exe 在目标机器双击即可解压（默认解压到 exe 所在目录），无需安装任何软件。
- FR-93 **分卷压缩**：按设定大小切分分卷；分卷序列可被 7-Zip / WinRAR 正常识别并解压；分卷与固实/加密可同时使用。
- FR-94 **压缩后删除源文件**：仅当压缩包创建成功且测试通过后才删除源文件；删除失败记录日志并提示，压缩包保留。

### 3.13 解压增强（v2.0 新增）

- FR-95 **批量解压**：主界面"工具 → 批量解压…"或右键菜单支持一次选择多个压缩包，每个压缩包解压到其所在目录下的独立同名文件夹；按队列依次执行，统一显示总进度与当前包名，支持取消；单个包失败不中断队列，完成后汇总成功/失败清单。
- FR-96 **解压后删除源压缩包**：解压对话框与批量解压提供"解压完成后删除源压缩包"选项；仅当该包全部内容解压成功后才删除。
- FR-97 **磁盘空间不足提醒**：解压前估算输出目录所在盘的剩余空间，若小于压缩包原始总大小的 1.2 倍，弹出警告并可选择继续或取消。
- FR-98 **tar.gz / tar.bz2 一次解完**：解压 .tar.gz/.tgz/.tar.bz2 等二层压缩包时自动连续解出最终内容，不在输出目录残留中间 .tar 文件。
- FR-99 **乱码修复**：打开压缩包后，工具栏/菜单提供"文件名编码"切换（自动/UTF-8/GBK/Big5/Shift-JIS/EUC-KR 等），切换后用对应编码重新解析文件名并刷新列表，解决早期压缩包在非中文系统创建时的乱码问题；选择记忆到 settings.json，作为下次打开的默认编码。

### 3.14 密码管理（v2.0 新增）

- FR-100 **密码库**：本地 `config/passwords.json` 明文保存成功使用过的密码（去重、按最近使用排序，上限 50 条）。
- FR-101 **自动尝试密码**：打开加密压缩包时，先按密码库顺序自动尝试；某条密码成功则直接打开并将其置顶；全部失败再弹出密码输入框。
- FR-102 **密码输入框增强**：密码输入对话框提供下拉框列出密码库历史密码，可直接选择；输入新密码并验证成功后自动写入密码库。
- FR-103 **密码库管理**：设置窗口提供"密码管理"页，可查看（明文）、删除单条、清空全部密码，操作写入日志。

### 3.15 包内浏览增强（v2.0 新增）

- FR-104 **包内搜索**：主界面提供搜索框，按条目名称实时模糊过滤列表（不区分大小写），清空后恢复完整列表；状态栏显示"已过滤 x / 共 y 项"。
- FR-105 **图片预览**：双击包内图片条目（.png/.jpg/.jpeg/.bmp/.gif/.webp）时，弹出预览窗口直接显示图片（解压到内存流，不落盘）；预览窗口支持缩放（滚轮）、适应窗口、上一张/下一张切换；加密条目先验证密码。
- FR-106 非图片条目双击行为不变（解压选中项）。

### 3.16 校验工具（v2.0 新增）

- FR-107 **MD5 校验工具**：菜单"工具 → MD5 校验"打开工具窗口，支持：
  - 拖入或选择本地文件，计算并显示 MD5 / SHA1 / SHA256 / CRC32；
  - 粘贴校验值比对，一致/不一致给出明显标识；
  - 大文件计算显示进度并可取消。
- FR-108 **包内条目 MD5**：压缩包列表右键菜单提供"计算 MD5"，对选中文件条目在内存流中计算 MD5 并弹出结果，可一键复制。

### 3.17 压缩包修复（v2.0 新增）

- FR-109 **修复压缩包**：菜单"工具 → 修复压缩包…"与压缩包右键菜单"使用 MZip 修复"：
  - 仅支持 ZIP 格式（RAR/7Z 提示不支持）；
  - 对目录损坏的 ZIP 尝试扫描本地文件头重建中央目录，输出 `<原名>_repaired.zip` 到同目录，不覆盖原文件；
  - 修复结果（恢复条目数、失败原因）弹窗展示并写日志；
  - 修复为尽力而为，不保证 100% 恢复。

### 3.18 右键菜单增强（v2.0 新增）

- FR-110 **级联菜单收纳**：MZip 在资源管理器右键的所有菜单项收纳到名为"MZip"的级联菜单（顶层仅显示一项，带图标），展开后按场景显示子项；设置中提供开关可退回平铺模式。
- FR-111 **文件/文件夹右键新增**：
  - 添加到"<名称>.zip"（按 ZIP 默认参数直接压缩，不弹对话框）；
  - 添加到高压缩比"<名称>.7z"（7Z + 最好级别 + 固实，直接压缩）；
  - 添加到压缩文件…（打开主程序新建压缩对话框，并自动带入所选路径）。
- FR-112 **压缩包右键新增**：
  - 解压文件…（弹出输出目录选择对话框后解压）；
  - 使用 MZip 修复（ZIP 时可用，其余格式置灰）。
- FR-113 新增右键项与既有项（压缩、解压到本目录、解压到指定目录）共存，注册/移除仍由设置界面统一控制，全部操作写日志。

## 4. 非功能需求

- NFR-01 大文件解压/压缩不阻塞界面（后台线程 + 进度回报），可取消。
- NFR-02 单次操作资源占用受控，不将压缩包整体载入内存；图片预览仅将单张图片载入内存。
- NFR-03 程序可在 Windows 10/11 x64 上直接运行（自带 .NET 8 运行时依赖说明）。
- NFR-04 内置 7-Zip 版本信息在"关于"中展示，并附 LGPL 授权说明；7z.sfx 同为 7-Zip 官方组件，随 7-Zip 授权发布。
- NFR-05 系统集成仅限当前用户，不弹出 UAC，不修改系统级 HKLM 关联。
- NFR-06 图标需覆盖 16/24/32/48/64/128/256 像素，小尺寸下仍可辨识；不因缩放出现明显锯齿。
- NFR-07 安装包不要求管理员权限，安装过程不写 HKLM 与 Program Files；安装包总大小控制在自包含发布产物的合理范围内（LZMA2 压缩）。
- NFR-08 批量解压队列化执行，单个包异常不导致程序崩溃；队列可取消，取消后已完成的结果保留。
- NFR-09 密码库文件仅当前用户可读写（置于程序目录 config 下，继承目录 ACL）。

## 5. 验收标准

1. 可创建 ZIP、7Z 压缩包，压缩包可被 Windows 资源管理器 / 7-Zip 正常解压。
2. 可解压 ZIP、7Z、RAR（含 RAR5 与加密 RAR，密码正确时）。
3. 中文文件名在压缩/解压全流程无乱码；对 GBK 编码的历史压缩包，切换"文件名编码 = GBK"后乱码消失。
