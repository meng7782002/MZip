# MZip 安装自动集成（右键菜单 + 文件关联）需求与技术变更

- 版本：v2.1（增量变更，基于需求规格说明书 v2.0 / 技术方案设计 v2.0）
- 日期：2026-11-07 11:15
- 变更类型：新增需求
- 影响范围：安装包、App 启动参数、Windows 系统集成

## 1. 需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-119 | 安装后自动注册 | 安装程序完成文件复制后，自动注册压缩包文件关联与资源管理器右键菜单，无需用户手动进入设置页 |
| FR-120 | 卸载后自动清理 | 卸载时自动移除 MZip 写入的文件关联、右键菜单，并恢复压缩文件原图标 |

补充约束：

1. 注册仅写 `HKCU`，跟随安装用户，不要求管理员权限；
2. 安装/卸载过程静默执行，不弹出主窗口、不弹确认框；
3. 注册失败不阻断安装或卸载（记录日志，用户仍可在设置页手动注册）；
4. 幂等：重复安装或重复注册不产生重复菜单项；
5. 卸载只清理本程序写入项，不破坏用户已改选的其他默认程序。

## 2. 技术设计

### 2.1 新增命令行参数

`App.OnStartup` 新增两个静默命令（`/` 与 `--` 前缀通用）：

| 参数 | 行为 |
| --- | --- |
| `/register` | 调用 `RegisterFileAssociation()` + `RegisterContextMenu(CascadedMenu)` + `NotifyShellChanged()`，随后退出，不创建主窗口 |
| `/unregister` | 调用 `UnregisterContextMenu()` + `UnregisterFileAssociation()` + `NotifyShellChanged()`，随后退出 |

- 级联模式取自 `config\settings.json` 的 `CascadedMenu`（默认 `false` 平铺）；
- 复用既有 `exitAfterCollect` 分支实现"无窗口退出"；
- 异常统一写入 `logs`，不影响进程退出。

### 2.2 安装包集成（Inno Setup）

```ini
[Run]
Filename: "{app}\{#MyAppExeName}"; Parameters: "/register"; Flags: runhidden waituntilterminated

[UninstallRun]
Filename: "{app}\{#MyAppExeName}"; Parameters: "/unregister"; Flags: runhidden waituntilterminated; RunOnceId: "MZipUnregister"
```

- `[Run]` 在文件复制完成后执行，静默安装（`/VERYSILENT`）同样生效；
- `[UninstallRun]` 在卸载删除文件之前执行，确保 `MZip.exe` 仍可用；
- `runhidden` 不显示控制台/窗口，`waituntilterminated` 保证注册完成后再结束安装流程。

## 3. 影响与风险

| 项 | 说明 |
| --- | --- |
| 默认关联 | Win10/11 的 UserChoice 受系统哈希保护，安装只写入 `HKCU\Software\Classes` 与能力登记；若系统已有其他默认程序，仍需用户在"默认应用"中改选 |
| 已有用户配置 | 升级安装会按当前设置重新注册右键菜单（幂等，不重复） |
| 卸载残留 | 若用户在卸载前删除 `MZip.exe`，`/unregister` 无法执行，菜单项会残留，需手动清理注册表 |
| 安全 | 不写 `HKLM`，不影响其他用户；图标原值已备份，卸载时按备份恢复 |

## 4. 验收标准

1. 静默安装后：`HKCU\Software\Classes\*\shell\MZip.Compress` 等菜单项存在；`.zip/.rar/.7z` 的 ProgID 指向 `MZip.Archive`；
2. 安装过程无窗口闪现；
3. 静默卸载后：上述 MZip 菜单键与 ProgID 关联被清除，压缩文件图标恢复；
4. 重复执行 `/register` 不产生重复菜单；
5. 注册异常时安装继续完成，日志包含错误堆栈。
