# 压缩解压工具 技术方案设计

- 版本：v2.0
- 日期：2026-11-07 09:38
- 项目：MZip（WPF / .NET 8）
- 对应需求：需求规格说明书 v2.0（新增 FR-90 ~ FR-118，对齐 360 压缩核心功能）

## 1. 总体架构

```
┌──────────────────────────────────────────────────────────┐
│                      MZip.exe (WPF/.NET 8)                │
│  MainWindow / Dialogs / 工具窗口(MD5,预览,批量解压,修复)    │
├──────────────────────────────────────────────────────────┤
│  Services                                                 │
│   ├─ SevenZipEngine     7z.exe 命令行封装(列表/解/压/改/删/测)│
│   ├─ SfxService(新)     EXE自解压包生成(7z.sfx+配置)        │
│   ├─ PasswordVault(新)  密码库(passwords.json,明文)         │
│   ├─ HashService(新)    MD5/SHA1/SHA256/CRC32 计算          │
│   ├─ ZipRepairService(新) ZIP中央目录重建修复               │
│   ├─ EncodingService(新) 文件名编码转换(GBK/Big5/SJIS...)   │
│   ├─ ShellIntegrationService 注册表关联+右键级联菜单         │
│   ├─ SettingsService    settings.json 持久化               │
│   └─ LogHelper          log4net                            │
├──────────────────────────────────────────────────────────┤
│  tools\7z.exe  tools\7z.dll  tools\7z.sfx(新增)             │
└──────────────────────────────────────────────────────────┘
```

技术选型原则：优先使用成熟开源组件（7-Zip 官方命令行 + 7z.sfx，LGPL 可商用），自研代码只做流程编排与界面。

## 2. 新增功能实现方案

### 2.1 自解压 EXE（FR-92）

- 组件：从 7-Zip 官方发行包提取 `7z.sfx`（与 7z.exe 同版本），放入 `tools\`，随安装包分发；关于窗口注明 LGPL 授权。
- 生成流程：
  1. 先用 7z.exe 以 7Z 格式压缩源文件到临时文件 `temp.7z`；
  2. 二进制拼接：`7z.sfx + 配置块(可选) + temp.7z` 写入目标 exe；
  3. 配置块采用 7z.sfx 标准 config.txt（UTF-8，含 `Title`/`BeginPrompt`/`ExtractTitle`/`Directory=""` 表示默认解到 exe 所在目录），用 `;!@Install@!UTF-8!` 头尾标记包裹；
  4. 拼接顺序：`[7z.sfx][config.txt][archive.7z]`，config 以 `;!@InstallEnd@!` 结束。
- 取消/失败清理：临时 7z 与半成品 exe 均删除。
- 分卷/密码可与 EXE 组合：加密 7Z 嵌入后，自解压运行时 sfx 会自行提示密码。

### 2.2 分卷压缩（FR-93）

- 7z.exe 参数：`-v{size}m`（如 `-v10m`）。
- 与 `-sfx` 互斥：EXE 自解压不支持分卷，对话框中选择 EXE 时禁用分卷输入。
- 输出：`xxx.7z.001/.002…` 或 `xxx.zip.001…`；FR-22 完成后打开主包 `.001`。
- 命令行长度校验沿用现有 `ValidateCommandLength`。

### 2.3 固实压缩与注释（FR-90）

- 固实：7Z 追加 `-ms=on`；ZIP 无固实概念，选项置灰。
- 注释：ZIP 归档注释 7z.exe 命令行不直接支持，采用后处理——压缩成功后用 `System.IO.Compression`（ZipArchive.Update 模式读写 `ArchiveComment`？.NET 8 的 ZipArchive 不支持写注释）→ 改为手写：ZIP 结构末尾 `End of Central Directory` 记录追加 UTF-8 字节注释（EOCD.CommentLength + Comment），用 `BinaryReader/Writer` 实现，约 40 行，无第三方依赖。7Z 不支持注释，选择 7Z 时隐藏注释框。

### 2.4 压缩后删除源文件（FR-94）

- 压缩成功 → 调用 `TestAsync` 校验 → 校验通过才删除源文件/文件夹（`File.Delete` / `Directory.Delete(recursive:true)`）。
- 删除用 try/catch 逐项执行，失败项记录日志并在完成提示中列出；压缩包本身保留。
- 校验失败时不删除任何源文件，提示"压缩包校验未通过，已保留源文件"。

### 2.5 记忆上次压缩参数（FR-91）

- `SettingsService` 增加 `LastCompressOptions` 节点（格式/级别/分卷/固实/删除源文件/加密文件名），对话框确认时保存，打开时回填；密码不回填。

### 2.6 批量解压（FR-95）

- 新窗口 `BatchExtractWindow`：列表展示待解压包（拖入/浏览添加/移除），选项含输出位置（各包所在目录下同名文件夹 / 统一指定目录）、覆盖策略、解压后删除源包。
- 执行模型：`SemaphoreSlim(1,1)` 队列依次调用 `SevenZipEngine.ExtractAsync`；总进度 = 已完成包数/总数 + 当前包内进度加权；每包独立 try/catch，失败记录继续；取消时中断当前包并停止队列。
- 完成后展示结果清单（成功 ✓ / 失败 ✗ + 原因），可一键打开输出目录。

### 2.7 解压后删除源压缩包（FR-96）

- 解压成功（ExitCode=0 且无密码错误）后 `File.Delete(archivePath)`；分卷包需删除整个 `.001~.00n` 序列（按命名规则匹配同前缀分卷）。
- 删除失败仅警告不报错。

### 2.8 磁盘空间不足提醒（FR-97）

- 解压前：`new DriveInfo(outputRoot).AvailableFreeSpace` 与 `ArchiveInfo.TotalSize * 1.2` 比较；不足则弹确认框（继续/取消）。
- RAR 等加密列表拿不到总大小时跳过检查。

### 2.9 tar.gz 一次解完（FR-98）

- 7z.exe 单命令对 `.tar.gz` 直接 `x` 会先解出 tar；方案：检测扩展名（`.tar.gz/.tgz/.tar.bz2/.tbz2/.tar.xz/.txz`）→ 先 `x` 到临时子目录得到 tar → 再对 tar 执行 `x` 到最终目录 → 删除临时目录。
- 进度两阶段映射（0-50% 解压 gz，50-100% 解 tar）。

### 2.10 乱码修复（FR-99）

- 原理：7z.exe 列表输出按 `-sccUTF-8` 返回，早期 GBK/Big5/SJIS 压缩包的文件名在 ZIP 中以本地代码页存储，7-Zip 默认按 UTF-8/CP437 解释导致乱码。
- 实现：增加 `-mcp=<codepage>` 参数支持（7-Zip 支持 `-mcp=936/950/932/949/65001`），`SevenZipEngine.ListAsync` 增加 `codePage` 参数；工具栏"编码"下拉切换后重新 List 并刷新。
- 记忆：settings.json `DefaultCodePage`；"自动"= 不传 -mcp。

### 2.11 密码库（FR-100 ~ FR-103）

- `PasswordVault`：`config/passwords.json`，`List<string>` 明文，MRU 排序，上限 50（超出淘汰最旧）。
- 自动尝试：打开加密包流程——List 失败且判定为密码问题 → 依次以密码库每条重试 List → 成功即置顶该密码并返回；全部失败弹 `PasswordDialog`（带下拉历史）。
- 手动输入成功 → `PasswordVault.Add`。
- 设置窗口新增"密码管理"页：ListBox 展示明文密码、删除选中、清空全部按钮；操作写日志。

### 2.12 包内搜索（FR-104）

- MainWindow 工具栏加 `TextBox`，`TextChanged`（300ms 防抖）→ 对 `ArchiveInfo.Entries` 按 `FullPath.Contains(keyword, OrdinalIgnoreCase)` 过滤 → 重绑 ItemsSource；状态栏显示"已过滤 x / 共 y 项"。
- 纯内存过滤，无引擎调用。

### 2.13 图片预览（FR-105）

- 新窗口 `ImagePreviewWindow`：双击图片条目（扩展名白名单 .png/.jpg/.jpeg/.bmp/.gif/.webp）→ `SevenZipEngine.ExtractEntryToStreamAsync`（`x -so <archive> <entry>` 输出到 stdout 流）→ `BitmapImage`（`stream + CacheOption.OnLoad`）显示。
- 功能：滚轮缩放（ScaleTransform）、适应窗口/实际大小切换、左右键或按钮切换同目录下上一张/下一张图片；加密条目使用当前会话密码。
- GIF 用 `WpfAnimatedGif`？——为控制依赖，GIF 以首帧静态显示，文档中注明。
- 内存控制：单张图片流读完即关，大图（>50MB 解压后）提示不预览。

### 2.14 MD5 校验工具（FR-107/108）

- `HashService`：`IncrementalHash`（.NET 内置）流式计算 MD5/SHA1/SHA256；CRC32 自实现查表法（30 行，无依赖）。
- `HashToolWindow`：拖入文件/浏览选择 → 后台线程计算（进度按字节回报，可取消）→ 显示四列值；粘贴框输入期望值自动比对，一致绿底/不一致红底。
- 包内 MD5：右键"计算 MD5"→ `x -so` 流式输出选中条目 → 流式 MD5 → 结果弹窗 + 复制按钮。

### 2.15 修复压缩包（FR-109）

- `ZipRepairService`：仅 ZIP。
  1. 顺序扫描文件，按 `PK\x03\x04` 本地文件头签名遍历：读取 flags/方法/尺寸（若 bit3 数据描述符置位则按下一个 `PK` 签名搜索定位数据末端）；
  2. 收集所有成功解析的条目信息（文件名、压缩方法、偏移、尺寸、CRC）；
  3. 重建中央目录 + EOCD 写入 `<name>_repaired.zip`（复制原始压缩数据，不重压缩）；
  4. 返回恢复条目数；写入过程流式，避免大文件占内存。
- RAR/7Z：提示"暂不支持修复该格式"。

### 2.16 右键菜单级联增强（FR-110 ~ FR-113）

- 级联实现（HKCU，无 COM）：
  - 顶层：`HKCU\Software\Classes\*\shell\MZip`（`MUIVerb=MZip`、`Icon`、`SubCommands=` + `ExtendedSubCommandsKey` 方式在 Win10/11 需 `ExplorerCommandHandler` COM——不可行）；
  - 替代方案（纯注册表可实现）：使用 `SubCommands` + 在 `HKCU\Software\Classes\*\shell\MZip\shell\01xxx\command` 逐子项注册。Win11 新菜单对 `SubCommands` 支持：注册表级联菜单在 Win11 经典菜单（Shift+右键/"显示更多选项"）中生效，新菜单仅显示顶层一项。**为兼容 Win11 新菜单**，提供设置开关：`级联收纳（经典菜单）/平铺（默认，全部上 Win11 新菜单）`，默认平铺以保证可见性——此点写入使用说明。
- 新增项：
  - `*\shell\MZip` 下：`压缩到"<名称>.zip"`（`MZip.exe /zip "%1"`）、`压缩到高压缩比 7Z`（`/7zsolid "%1"`）、`添加到压缩文件…`（`/add "%1"` 拉起主程序对话框）；
  - 压缩包 ProgID 下：`解压文件…`（`/extractto "%1"`）、`使用 MZip 修复`（`/repair "%1"`，非 ZIP 置灰用 `CommandFlags` 按扩展名分别注册，仅 ZIP ProgID 注册此项）。
- 多选路径汇总沿用现有命名互斥量+命名管道（ShellCommandCollector），`/zip`、`/7zsolid` 命令复用该机制合并多选为一个包。

### 2.17 命令行入口扩展（App.xaml.cs）

新增启动参数解析：
| 参数 | 行为 |
| --- | --- |
| `/zip <路径…>` | 按默认 ZIP 参数直接压缩到本目录（不弹对话框） |
| `/7zsolid <路径…>` | 7Z+mx9+固实直接压缩 |
| `/add <路径…>` | 打开主窗口并弹出新建压缩对话框，已带入路径 |
| `/extractto <包>` | 弹目录选择后解压 |
| `/repair <包>` | 执行修复并弹结果 |
| `/batch <包…>` | 打开批量解压窗口并带入列表 |

## 3. 数据与配置

- `config/settings.json` 新增字段：
  - `LastCompressOptions { Format, Level, VolumeMB, Solid, DeleteSources, EncryptNames }`
  - `DefaultCodePage`（0=自动）
  - `ExtractDeleteSource`（默认 false）
  - `CascadedMenu`（默认 false=平铺）
- `config/passwords.json`：`["pwd1","pwd2",…]`，MRU，≤50 条，明文（用户规则允许）。

## 4. 日志

新增关键节点日志：批量解压开始/每包结果/汇总、删除源文件逐项结果、编码切换、密码自动尝试（记录"第n条命中"，不记录密码内容）、修复扫描/重建结果、MD5 计算、右键新命令触发。全部经 `LogHelper`。

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 7z.sfx 与 7z.exe 版本不一致导致 exe 无法解 | 从同一 7-Zip 发行包提取，安装包内置固定版本 |
| ZIP 注释手写 EOCD 出错损坏包 | 写完后用 `TestAsync` 校验，失败回滚原文件 |
| 分卷+删除源文件误删 | 校验 `.001` 主包通过才删源；分卷序列整体保留 |
| 密码库明文泄露 | 规则允许明文；文件置于 config，提示用户勿共享该目录 |
| Win11 新右键菜单不支持级联 | 默认平铺，级联为可选开关并注明仅经典菜单生效 |
| 修复 ZIP 误判签名 | 逐条校验本地头 CRC/尺寸合理性，异常条目跳过并计数 |
