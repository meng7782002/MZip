# 压缩解压工具 技术方案设计

- 版本：v1.0
- 日期：2026-11-02 08:45
- 项目：QuickZip（WPF / .NET 8）

## 1. 总体架构

```
QuickZip (WPF .NET 8)
 ├─ MainWindow.xaml / MainWindow.xaml.cs   界面与事件（无 MVVM，直接代码后置）
 ├─ Dialogs/                               创建压缩包、密码、覆盖策略、关于等对话框
 ├─ Models/ArchiveItem.cs                  压缩包条目实体
 ├─ Services/SevenZipEngine.cs             7-Zip 命令行封装（列表/解压/压缩/追加/删除/测试）
 ├─ Services/ProcessRunner.cs              进程执行、stdout 解析、进度回调、取消
 ├─ Services/SettingsService.cs            config/settings.json 读写
 ├─ Services/LogHelper.cs                  log4net 初始化与封装
 └─ tools/7z.exe + 7z.dll                  内置 7-Zip 引擎（LGPL）
```

不使用接口、不使用 MVVM、不使用依赖注入，全部为普通实体类与静态/实例方法，便于调试。

## 2. 压缩引擎选型

| 方案 | 结论 |
| --- | --- |
| SharpCompress（MIT） | 可读写 ZIP，可读 7Z/RAR，但 **不能写 7Z**，RAR5 支持不完整 |
| 7-Zip 官方命令行（LGPL + unRAR 限制） | 列表/解压/压缩/测试/删除全格式覆盖，RAR5 与 AES 加密支持完善，可商用免费 |

最终采用 **内置 7-Zip 26.05 x64**（`tools/7z.exe`、`tools/7z.dll`），通过进程调用，参数统一使用：

- `-sccUTF-8`：控制台输出 UTF-8，避免中文乱码
- `-slt`：详细列表输出，便于逐条解析
- `-bsp1`：进度百分比输出到 stdout
- `-y`：自动确认覆盖（覆盖策略在应用层实现）

### 关键命令

| 功能 | 命令 |
| --- | --- |
| 列表 | `7z l -slt -sccUTF-8 [-p密码] 压缩包` |
| 解压全部 | `7z x -o输出目录 -y -bsp1 -sccUTF-8 [-p密码] 压缩包` |
| 解压选中 | `7z x -o输出目录 -y -bsp1 -sccUTF-8 [-p密码] 压缩包 条目1 条目2 ...` |
| 创建 | `7z a -t7z\|-tzip -mx=N [-p密码] [-mhe=on] -bsp1 -sccUTF-8 目标 @列表文件` |
| 追加 | `7z a -t... -mx=N [-p密码] -bsp1 压缩包 @列表文件` |
| 删除 | `7z d -y [-p密码] 压缩包 条目1 条目2 ...` |
| 测试 | `7z t -sccUTF-8 [-p密码] 压缩包` |

文件列表通过 `@listfile` 传入（UTF-8 编码），避免命令行长度限制与引号转义问题。

## 3. 进度与取消

- `ProcessRunner` 异步读取 stdout/stderr，正则匹配 `(\d+)%` 更新进度。
- 解压/压缩回调 `Action<double,string>`（百分比、当前条目）。
- 取消：`process.Kill(entireProcessTree: true)`，并将 CancellationToken 传递到 UI 状态复位。
- stdout/stderr 全部收集到日志（Debug 级别），失败时输出完整 7-Zip 信息。

## 4. 列表解析

`7z l -slt` 输出为 `键 = 值` 的块结构，块之间空行分隔。解析规则：

- 首个块为压缩包自身信息（`Path = 压缩包路径`），跳过。
- 后续块以 `Path =` 开始，读取 `Folder`、`Size`、`Packed Size`、`Modified`、`Attributes`、`CRC`、`Encrypted` 字段。
- 目录条目（`Folder = +`）在界面上以文件夹图标展示，不参与大小统计。
- 日期字符串格式 `yyyy-MM-dd HH:mm:ss` 直接解析，解析失败则置空。

## 5. 界面设计

- 顶部工具栏：打开、解压全部、解压选中、新建、添加、删除、测试、刷新、设置、关于。
- 中部：路径面包屑 + 汇总信息条 + 条目 DataGrid（名称/大小/压缩后/压缩率/修改时间/CRC/属性/加密）。
- 底部：状态文本 + 进度条 + 取消按钮。
- 视觉：浅色主题，强调色 #2F6FED，圆角卡片式工具栏，Segoe MDL2 图标。
- 拖拽：窗口整体接受文件拖放；文件列表支持拖入作为“添加”源。
- 用户偏好：仅展示必要信息，不放置多余装饰；控件位置固定。

## 6. 日志

- log4net，配置文件 `log4net.config` 随程序发布。
- 输出：`logs/quickzip-yyyy-MM-dd.log`，按天滚动，保留 30 天。
- 级别：INFO（启动、打开、操作开始/完成）、DEBUG（7-Zip 原始输出）、ERROR（异常堆栈）。
- 未捕获异常（UI 线程、后台任务）统一记录。

## 9. 异常与边界处理

- 找不到 `7z.exe`：提示“压缩引擎缺失”，并记录日志。
- 密码错误：7-Zip 返回码 2 且输出包含 `Wrong password`，转为中文提示并可重新输入。
- 条目名包含非法字符/路径穿越（`..`）：解压时由 7-Zip 处理，应用层仅按 7-Zip 结果提示。
- 取消：返回码非 0 但标记为用户取消，不弹错误。
- 文件被占用：提示“文件正在被其他程序使用”。

## 10. 验证方式

1. 用 PowerShell/命令行直接验证 7-Zip 参数与输出格式。
2. 运行程序，创建 ZIP/7Z（含中文名、加密），再用资源管理器/7-Zip 校验。
3. 用 7-Zip 生成 RAR 测试样本（借用本机临时安装的 WinRAR 或公共测试包），验证 RAR/RAR5 解压。
4. 检查日志文件与取消、异常场景。
