# QuickZip 使用说明

- 版本：v1.5
- 日期：2026-11-02 16:55
- 适用程序：QuickZip（WPF / .NET 8，内置 7-Zip 26.05 引擎）
- 本版新增：“关于”窗口显示开发单位与版权信息

## 1. 运行环境与启动

- 系统要求：Windows 10/11 x64，已安装 .NET 8 Desktop Runtime。
- 发布目录内需包含 `tools\7z.exe`、`tools\7z.dll`（构建时自动复制）。
- 双击 `QuickZip.exe` 启动；也可将压缩包拖到程序图标上，或使用命令行 `QuickZip.exe "压缩包路径"` 直接打开。
- 程序图标会显示在可执行文件、任务栏、窗口标题栏和“关于”窗口中。

## 2. 支持格式

| 能力 | 格式 |
| --- | --- |
| 解压 / 浏览 / 测试 | ZIP、7Z、RAR、TAR、GZ、TGZ、BZ2、XZ、ISO、CAB、JAR、APK、分卷 001 等 |
| 新建 / 添加 / 删除条目 | ZIP、7Z |
| 加密 | ZIP（AES-256）、7Z（可加密文件名） |

RAR 为专有压缩格式，免费引擎只能解压，不能创建或修改。

## 3. 打开压缩包

- 点击工具栏“打开”或菜单“文件 → 打开压缩包…”，快捷键 Ctrl+O。
- 从“文件 → 最近打开”中快速选择最近使用的压缩包（最多 10 条）。
- 空状态下直接把压缩包拖入窗口即可打开。
- 加密文件名的 7Z/RAR 会弹出密码框；密码错误会提示并允许重新输入。

## 4. 浏览与解压

- 列表显示条目完整路径、大小、压缩后大小、压缩率、修改时间、CRC、属性，加密条目带“加密”徽章。
- “解压全部”：选择输出目录后解压全部内容。
- “解压选中”：在列表中选中一个或多个条目（支持 Ctrl/Shift 多选），点击“解压选中”或双击条目。
- 覆盖策略在“设置”中配置：每次询问 / 直接覆盖 / 跳过已有 / 自动重命名。
- 解压完成后可选择是否打开输出目录。

### 4.1 复制条目并粘贴到指定位置

1. 打开压缩包后，按 Ctrl+A 或“操作 → 全选条目”选中全部文件（也可用 Ctrl/Shift 手动多选部分条目）。
2. 按 Ctrl+C 或“操作 → 复制选中条目”，状态栏提示已复制的条目数量；列表右键菜单同样提供这两个命令。
3. 按 Ctrl+V 或“操作 → 粘贴到指定文件夹…”，选择目标文件夹，条目会直接解压到该文件夹（不再创建同名子目录）。
4. 覆盖策略按“设置”中的配置执行；设置为“每次询问”时会弹出覆盖策略对话框。
5. 粘贴使用复制时的来源压缩包：即使之后打开或关闭了其他压缩包仍可粘贴；若来源文件已被删除或移动，会提示且不解压。

## 5. 新建压缩包

1. 点击“新建”，在对话框中添加文件或文件夹（可多选）。
2. 选择格式：7Z 或 ZIP；选择压缩级别（0 存储 ~ 9 极限）。
3. 可选设置密码；7Z 支持“加密文件名”，ZIP 使用 AES-256 加密。
4. 确认保存路径（默认根据来源自动建议），点击“创建”。
5. 创建完成后自动打开生成的压缩包。

不能将压缩包保存到被压缩的文件夹内部，程序会阻止并提示。

## 6. 修改压缩包（仅 ZIP / 7Z）

- “添加”：向当前压缩包追加文件或文件夹；已打开压缩包时也可以直接把文件拖入窗口。
- “删除”：删除选中条目，操作不可撤销，执行前会二次确认。
- “刷新”（F5）：重新读取条目列表。

## 7. 校验与取消

- “测试”执行完整性校验，成功或失败均给出结果提示。
- 操作过程中状态栏显示进度条与百分比，点击“取消”或按 Esc 可终止当前操作。

## 8. 设置

菜单“工具 → 设置”可调整：

- 默认压缩格式（7Z / ZIP）
- 默认压缩级别
- 覆盖策略
- 默认输出目录
- Windows 系统集成（见第 9 节）

设置以明文 JSON 保存在程序目录 `config\settings.json`。

### 8.1 关于 QuickZip

点击菜单“工具 → 关于”或工具栏“关于”按钮，可查看程序版本、内置 7-Zip 引擎版本，以及开发单位“西安极速聚米软件科技有限公司”和版权信息“版权所有 © 西安极速聚米软件科技有限公司”。右键 `QuickZip.exe` → 属性 → 详细信息，也可看到相同的公司信息。

## 9. Windows 系统集成

所有注册项只写入当前用户注册表（HKCU），无需管理员权限，也不影响其他用户账户。

### 9.1 关联为默认解压程序

1. 打开“设置”，在“Windows 系统集成”卡片中点击“设为默认解压程序”。
2. 程序会把 `.zip`、`.rar`、`.7z` 注册为 QuickZip 可打开的类型，并在注册表中登记应用能力（“打开方式”列表中可见）。
3. 同时为这三类扩展名写入 QuickZip 图标，资源管理器中的压缩文件会立即显示该图标（无需重启资源管理器）。
4. Windows 10/11 的“默认应用”由系统哈希保护，程序不能强行改写。需要完全成为默认程序时，点击“打开默认应用设置”，在“按文件类型指定默认应用”中把 `.zip` / `.rar` / `.7z` 选择为 QuickZip。
5. 点击“取消关联”可撤销 QuickZip 写入的所有关联项，并把压缩文件图标恢复为注册前的状态。

状态文字会实时显示“已注册 / 未注册”。

### 9.2 资源管理器右键菜单

在“设置”中点击“注册右键菜单”后：

| 操作对象 | 右键菜单项 | 行为 |
| --- | --- | --- |
| 任意文件 | 使用 QuickZip 压缩 | 在该文件所在目录生成以文件名命名的 7Z 压缩包 |
| 文件夹 | 使用 QuickZip 压缩 | 在文件夹上级目录生成以文件夹名命名的 7Z 压缩包 |
| 多选文件/文件夹 | 使用 QuickZip 压缩 | 汇总所有选中项，只生成一个压缩包（以首个条目所在目录命名） |
| .zip / .rar / .7z 文件 | 解压到本目录 | 在压缩包同级创建同名文件夹，解压到该文件夹内 |
| .zip / .rar / .7z 文件 | 解压到指定目录… | 弹出目录选择框后解压 |

说明：

- 多选压缩时资源管理器会为每个条目启动一次进程，程序会在 600 毫秒静默窗口内汇总路径，只保留一个主窗口，其余实例自动退出。
- 同名压缩包已存在时自动追加序号，如 `备份 (1).7z`，不会覆盖已有文件。
- “解压到本目录”的目标文件夹若已存在则直接复用；文件夹内遇到同名文件时按“直接覆盖”处理（不弹询问），其他覆盖策略可在设置中改为跳过或自动重命名。
- 若压缩包同级已存在同名文件（而非文件夹），程序会提示并停止，避免误覆盖。
- 点击“移除右键菜单”可清理全部菜单项，随后资源管理器会自动刷新。

### 9.3 注册表位置

| 用途 | 路径 |
| --- | --- |
| 文件类型 ProgID | `HKCU\Software\Classes\QuickZip.Archive` |
| 扩展名关联 | `HKCU\Software\Classes\.zip` / `.rar` / `.7z` |
| 文件图标 | `HKCU\Software\Classes\.zip\.rar\.7z` 下的 `DefaultIcon` |
| 图标原值备份 | `HKCU\Software\QuickZip\IconBackup` |
| 压缩菜单 | `HKCU\Software\Classes\*\shell\QuickZip.Compress`、`...\Directory\shell\QuickZip.Compress` |
| 解压菜单 | `HKCU\Software\Classes\SystemFileAssociations\.{zip,rar,7z}\shell\QuickZip.ExtractHere` / `QuickZip.ExtractTo` |
| 应用能力登记 | `HKCU\Software\QuickZip\Capabilities`、`HKCU\Software\RegisteredApplications` |

## 10. 命令行参数

| 参数 | 说明 |
| --- | --- |
| `QuickZip.exe "压缩包路径"` | 启动并打开指定压缩包 |
| `QuickZip.exe --compress "路径1" ["路径2" …]` | 一键压缩，自动命名并生成 7Z |
| `QuickZip.exe --extract-here "压缩包路径"` | 解压到压缩包所在目录 |
| `QuickZip.exe --extract-to "压缩包路径"` | 选择目录后解压 |

## 11. 日志

- 日志目录：程序目录下 `logs`，文件名为 `quickzip<yyyy-MM-dd>.log`，按天滚动，保留约 30 份。
- 记录启动、命令参数、打开、解压/压缩/删除/校验、右键菜单注册与文件关联、图标注册与恢复等关键节点，以及全部异常堆栈。
- 反馈问题时请附带对应日期的日志文件。

## 12. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示“压缩引擎缺失” | 确认 `tools` 目录下存在 `7z.exe` 与 `7z.dll`，杀毒软件可能误删 |
| 打开加密压缩包一直提示密码 | 确认密码正确；RAR 老式加密与 ZIP 的 AES 加密需对应密码 |
| 解压提示“文件正在被其他程序使用” | 关闭占用该文件的程序后重试 |
| 中文文件名乱码 | 引擎已固定 UTF-8 输出，若仍异常请提供日志与压缩包样本 |
| 右键菜单未出现 | 在设置中确认状态为“已注册”，或先移除再重新注册；必要时重启资源管理器 |
| 双击压缩包仍由旧程序打开 | Windows 默认应用受系统保护，请点击“打开默认应用设置”手动指定 |
| 压缩文件图标未变化 | Windows 图标缓存可能未刷新，取消关联后重新注册；或重启资源管理器 |
