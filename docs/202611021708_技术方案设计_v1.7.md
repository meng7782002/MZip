## 2. 压缩引擎

沿用 v1.1：内置 7-Zip 26.05 x64，使用 `ProcessStartInfo.ArgumentList` 传参，`-sccUTF-8` 保证中文正常，`-bsp1 -bb1` 输出进度，始终传 `-p` 并关闭标准输入。覆盖策略映射 `-y` / `-aos -y` / `-aou -y`。

## 3. 命令行入口

`App.OnStartup` 解析参数：

| 参数 | 作用 |
| --- | --- |
| 无参数 / `<压缩包路径>` | 正常启动，或直接打开指定压缩包 |
| `--compress "<路径1>" ["路径2" ...]` | 右键“使用 QuickZip 压缩”，收集路径后在所在目录生成压缩包并打开 |
| `--extract-here "<压缩包>"` | 右键“解压到本目录”，解压到压缩包所在目录 |
| `--extract-to "<压缩包>"` | 右键“解压到指定目录…”，打开压缩包后弹出目录选择 |

命令行参数由 `ShellIntegrationService` 注册的命令模板传入，路径均使用 `"%1"` 加引号形式。

### 3.1 多选压缩的收集机制

Windows 资源管理器对注册表动词在多选时按“每个条目启动一次进程”执行，因此：

1. `--compress` 启动时尝试获取命名互斥量 `QuickZip.Compress.Collect`。
2. 获得互斥量的首个实例创建命名管道 `QuickZip.Compress`，在 600ms 静默窗口内（最长 5 秒）接收其他实例发来的路径，合并为一个列表。
3. 未获得互斥量的实例作为客户端连接管道，把自身路径发送给首个实例后立即退出（不创建窗口）。
4. 首个实例收集完成后释放互斥量，正常显示主窗口，并在 `Loaded` 后执行压缩。
5. 管道/互斥量名称固定，仅本地会话可见；客户端连接重试最多 4 秒，失败则忽略该路径并记录日志。

右键动词使用 `MultiSelectModel="Player"`（允许最多 100 项选择），并以 `*\shell`（文件）与 `Directory\shell`（文件夹）两处注册。

## 4. 系统集成（HKCU）

### 4.1 ProgID 与文件关联

```
HKCU\Software\Classes\QuickZip.Archive
 ├─ (默认) = QuickZip 压缩包
 ├─ DefaultIcon = "<程序路径>",0
 └─ shell\open\command = "<程序路径>" "%1"

HKCU\Software\Classes\.zip / .rar / .7z
 ├─ (默认) = QuickZip.Archive
 ├─ DefaultIcon = "<程序路径>",0        ← 本版新增，保证文件图标统一
 └─ OpenWithProgids\QuickZip.Archive（空值）
```

同时注册应用能力，使 QuickZip 出现在“默认应用”列表：

```
HKCU\Software\QuickZip\Capabilities
 ├─ ApplicationName = QuickZip
 ├─ ApplicationDescription = 支持 ZIP / 7Z / RAR 的压缩解压工具
 ├─ ApplicationIcon = "<程序路径>",0
 └─ FileAssociations\.zip/.rar/.7z = QuickZip.Archive

HKCU\Software\RegisteredApplications
 └─ QuickZip = Software\QuickZip\Capabilities
```

Windows 10/11 的 `FileExts\.ext\UserChoice` 受系统哈希保护，程序不写入；设置界面提供“打开默认应用设置”（`ms-settings:defaultapps`）让用户确认。

### 4.2 右键菜单

| 位置 | 键 | 菜单文字 | 命令 |
| --- | --- | --- | --- |
| 文件（多选） | `HKCU\Software\Classes\*\shell\QuickZip.Compress` | 使用 QuickZip 压缩 | `"<exe>" --compress "%1"` |
| 文件夹 | `HKCU\Software\Classes\Directory\shell\QuickZip.Compress` | 使用 QuickZip 压缩 | `"<exe>" --compress "%1"` |
| `.zip/.rar/.7z` | `HKCU\Software\Classes\SystemFileAssociations\.ext\shell\QuickZip.ExtractHere` | 解压到本目录 | `"<exe>" --extract-here "%1"` |
| `.zip/.rar/.7z` | `...\shell\QuickZip.ExtractTo` | 解压到指定目录… | `"<exe>" --extract-to "%1"` |

压缩动词带 `MultiSelectModel="Player"`；解压动词带 `MultiSelectModel="Single"`，并设置 `Icon` 为程序图标。

### 4.3 刷新与移除

- 注册/移除后调用 `SHChangeNotify(SHCNE_ASSOCCHANGED, SHCNF_IDLIST)` 通知资源管理器刷新。
- 移除仅删除本程序创建的键值；`.ext` 默认值只在等于 `QuickZip.Archive` 时清除；不触碰其他程序的关联。
- 所有注册/移除操作记录 INFO/ERROR 日志。

### 4.4 设置界面

设置窗口新增“Windows 集成”区域：

- 当前状态：已注册 / 未注册（文件关联、右键菜单分别显示）。
- 按钮：设为默认解压程序、打开默认应用设置、取消默认关联、注册右键菜单、移除右键菜单。
- 操作结果即时刷新状态文本，失败时中文提示并写日志。

### 4.5 应用图标与压缩文件图标（本版新增）

#### 4.5.1 图标资源

- 文件：`src\QuickZip\Assets\QuickZip.ico`，包含 16/24/32/48/64/128/256 像素帧，PNG 压缩帧。
- 设计：蓝色圆角方形底（#3B7BF0 → #2A5BD7 渐变），中央白色压缩符号（上下向内箭头 + 中央横条），无文字，透明四角。
- 构建：`QuickZip.csproj` 增加 `<ApplicationIcon>Assets\QuickZip.ico</ApplicationIcon>`，编译时嵌入 exe 资源（图标索引 0）。
- 界面：`MainWindow.xaml` 设置 `Icon="Assets/QuickZip.ico"`（pack URI），任务栏与标题栏跟随；资源管理器“属性 → 详细信息”显示该图标。

#### 4.5.2 文件图标写入

- ProgID `QuickZip.Archive\DefaultIcon` 继续使用 `"<exe 路径>",0`，随 exe 内嵌图标变化，无需额外图标文件。
- 为保证默认关联切换后 `.zip/.rar/.7z` 立即使用该图标，注册时同时写扩展名下的 `DefaultIcon`：
  ```
  HKCU\Software\Classes\.zip\DefaultIcon  (默认) = "<exe 路径>",0
  ```
- 写入前备份：若 `HKCU\Software\QuickZip\IconBackup\<ext>` 不存在，则记录原 `DefaultIcon` 默认值（无值时记录标记 `-`），避免覆盖其他程序的自定义图标信息。
- 取消关联时：存在备份则按备份恢复（备份为 `-` 则删除该值），随后删除 `IconBackup` 子树。
- 注册/取消后调用 `SHChangeNotify(SHCNE_ASSOCCHANGED, SHCNF_IDLIST)` 刷新图标缓存，立即生效。

#### 4.5.3 图标备份键

```
HKCU\Software\QuickZip\IconBackup\.zip  (默认) = 原 DefaultIcon 值 或 "-"
HKCU\Software\QuickZip\IconBackup\.rar  ...
HKCU\Software\QuickZip\IconBackup\.7z   ...
```

## 5. 右键压缩的命名规则

- 单个文件夹：`<文件夹名>.<7z|zip>`；
- 单个文件：`<文件名>.<7z|zip>`（不含原扩展名）；
- 多个条目：`<第一个条目所在目录名>.<7z|zip>`；
- 目标目录为第一个条目所在目录；同名文件已存在时追加 `(1)`、`(2)`，避免覆盖；
- 格式与压缩级别取设置中的默认值，右键压缩不设置密码。

## 6. 右键解压

- “解压到本目录”：输出目录 = `<压缩包所在目录>\<压缩包文件名（不含扩展名）>`，先创建该文件夹（已存在则复用），再复用主窗口的解压流程（密码重试、进度、取消、覆盖策略）；覆盖策略为“每次询问”时，一次性改为“直接覆盖”以保证一键完成，并在日志记录。若目标路径已存在同名文件而非文件夹，提示并写日志，不执行解压。
- “解压到指定目录…”：打开压缩包后弹出目录选择对话框，沿用“解压全部”流程。
- 解压完成后提示并可直接打开输出目录。

### 6.1 复制选中条目并粘贴到指定文件夹（本版新增）

- 内部剪贴板保存在 `MainWindow` 字段：`_copiedEntries`（条目路径列表）、`_copiedArchivePath`（来源压缩包）、`_copiedPassword`（复制时的密码）。不写入系统文件剪贴板，避免与资源管理器复制混淆。
- 复制入口：菜单“操作 → 复制选中条目”、列表右键菜单、Ctrl+C；无选中条目时状态栏提示。
- 粘贴入口：菜单“操作 → 粘贴到指定文件夹…”、右键菜单、Ctrl+V；使用 `OpenFolderDialog` 选择目标目录，默认定位到上次输出目录。
- 执行：`Directory.CreateDirectory` 后调用 `RunExtractionAsync`；该方法增加可选的来源压缩包与密码参数，使其可以对非当前打开的压缩包执行解压。覆盖策略为“每次询问”时弹出 `OverwriteDialog`。
- 结果：条目直接解压到所选文件夹，不创建同名子目录；完成后可选择打开输出目录。
- 异常：剪贴板为空、来源压缩包不存在、目录不可写时中文提示并写日志；Ctrl+C/Ctrl+V 在无压缩包或剪贴板为空时不拦截按键。

### 6.2 关于窗口（本版新增）

- 入口：菜单“工具 → 关于”与工具栏“关于”按钮，均调用 `MainWindow.About_Click`，以模态方式打开 `Dialogs/AboutWindow.xaml`；操作进行中（`_busy`）不打开。
- 展示内容：程序名 QuickZip、版本号 1.0.0、开发单位“西安极速聚米软件科技有限公司”、功能说明、7-Zip 引擎版本与 LGPL 说明、日志目录说明，以及“版权所有 © 西安极速聚米软件科技有限公司”。
- 程序集元数据：`QuickZip.csproj` 增加 `<Company>` 与 `<Copyright>`，使资源管理器“属性 → 详细信息”显示公司名与版权。

## 9. 异常与边界处理

- 右键压缩来源全部不存在/为空：不执行，记录日志并提示。
- 来源被自身占用或权限不足：按 7-Zip 错误信息中文提示。
- 文件关联写入失败（受组策略限制）：提示“注册失败，请检查权限或安全软件拦截”，写日志。
- 多选压缩时个别实例连接超时：忽略该路径并记录 WARN，剩余路径继续压缩。
- 解压目标目录不可写：提示并停止。
- 命令行动词中的路径包含空格/中文：命令模板全部加双引号，程序按参数原样接收。
- 图标备份读取失败或注册表受限：仍继续写入图标关联，仅记录 WARN，不阻断注册。
- 取消关联时备份缺失：直接删除本程序写入的 `DefaultIcon` 值，不影响其他键。

## 11. Windows 安装包（本版新增）

### 11.1 打包工具与发布方式

- 打包工具：Inno Setup 6（免费、可商用），编译命令 `ISCC.exe installer\QuickZip.iss`。
- 发布方式：`dotnet publish src\QuickZip\QuickZip.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -o build\publish`
  - 自包含发布，安装包不依赖目标机的 .NET 8 运行时；
  - 不使用单文件打包，避免 `tools\7z.exe` 无法释放到磁盘而被引擎调用。
- 发布目录中的 `tools\` 由 csproj 的 `None` 复制项自动带入。

### 11.2 Inno Setup 脚本要点

| 配置项 | 取值 |
| --- | --- |
| `AppId` | `{{8C0B0A2E-...}}` 固定 GUID，保证升级覆盖同一安装 |
| `AppName` | `QuickZip` |
| `AppVersion` | `1.0.0`（与 csproj `Version` 一致） |
| `AppPublisher` | 西安极速聚米软件科技有限公司 |
| `DefaultDirName` | `{localappdata}\Programs\QuickZip` |
| `PrivilegesRequired` | `lowest`（当前用户安装，无 UAC） |
| `Compression` | `lzma2/ultra64` |
| `SetupIconFile` | `src\QuickZip\Assets\QuickZip.ico` |
| `OutputDir` | `dist`，文件名为 `QuickZip-{#AppVersion}-Setup.exe` |
| `UninstallDisplayIcon` | `{app}\QuickZip.exe` |
| 语言 | `ChineseSimplified.isl` + 英文 |
| 快捷方式 | 开始菜单固定创建；桌面快捷方式为可选任务 `desktopicon` |
| 安装文件 | 整个 publish 目录（`recursesubdirs createallsubdirs`） |
| 运行选项 | 安装完成后可选“立即运行 QuickZip”（`postinstall nowait skipifsilent`） |
| 卸载数据 | 默认只删除安装的文件；`config`、`logs` 为用户数据不写入安装清单，卸载后保留 |

### 11.3 一键构建脚本

`scripts\build-installer.ps1` 依次执行：

1. 读取 csproj 中的 `Version`，用于输出文件名与日志；
2. `dotnet publish` 到 `build\publish`（先清理旧目录）；
3. 定位 `ISCC.exe`（常见安装路径与 PATH），未安装时给出安装提示并退出；
4. 调用 `ISCC.exe` 编译 `installer\QuickZip.iss`，输出到 `dist`；
5. 输出安装包路径与大小，失败时写入 `F:\AITEMP\quickzip-installer-build.log`（临时日志按用户规则放在 F:\AITEMP）。

### 11.4 卸载与系统集成的关系

- 程序的文件关联、右键菜单、文件图标注册均写入 HKCU，由程序“设置”中的按钮维护；安装包不自动注册。
- 卸载不主动清理上述 HKCU 注册项，避免误删用户自行建立的关联；用户可在卸载前点击“取消关联”，或在卸载后手动清理。
- 卸载程序本身通过 Inno Setup 生成的 `unins000.exe` 实现，并在“应用”列表中登记。
